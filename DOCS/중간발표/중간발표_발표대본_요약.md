# Dreammate Studio 중간발표 발표 대본 요약

## 시간 배분

- 프로젝트 소개 + 문제 정의: 2분
- 사용자 시나리오: 30초
- 핵심 기능: 30초
- 기술 스택과 선택 이유: 1분
- 아키텍처 + 지침설계 하네스: 1분
- 현재 진행 상황 + 데모 영상: 1분 30초
- 남은 일정: 30초

## 1. 프로젝트 소개 + 문제 정의

Dreammate Studio는 막연한 영상 아이디어를 실행 가능한 콘텐츠 기획안으로 바꿔주는 영상기획 AI 에이전트입니다.

초보 사용자는 영상 아이디어는 있어도 브랜드 방향, 타깃, 톤, 후킹, 컷 구성까지 한 번에 정리하기 어렵습니다. 기존 범용 AI는 좋은 결과를 얻으려면 사용자가 좋은 프롬프트를 직접 작성해야 합니다. 그래서 이 프로젝트는 AI가 먼저 질문하며 브랜드 방향과 타깃을 좁히고, 마지막에 영상 기획안까지 생성하는 흐름을 목표로 합니다.

## 2. 사용자 시나리오

사용자가 “대학생 창업 쇼츠를 만들고 싶다”처럼 짧게 입력합니다. AI는 바로 대본을 쓰지 않고 목표, 타깃, 톤, 피해야 할 방향을 질문합니다. 사용자가 답하면 AI가 브랜드 톤과 콘텐츠 목적을 정리하고, 제목, 후킹, 컷 구성, 30초 쇼츠 대본을 생성합니다.

## 3. 핵심 기능

핵심 기능은 세 가지입니다. 첫째, 질문 기반 브랜딩입니다. 둘째, 타깃과 톤 구조화입니다. 셋째, 영상 기획안 생성입니다. 중간 발표에서는 이 세 흐름만 집중해서 보여줍니다.

## 4. 기술 스택

프론트엔드는 Next.js PWA를 선택했습니다. 웹으로 빠르게 배포하고 앱처럼 확장할 수 있기 때문입니다. 백엔드는 FastAPI를 사용했습니다. Python 기반이라 LLM 호출과 테스트 구성이 빠릅니다. DB와 인증은 Supabase와 PostgreSQL을 사용했습니다. 사용자별 브랜드, 도메인, 시리즈, 영상 데이터를 저장하기 좋기 때문입니다. RAG와 PKM은 pgvector와 자체 RAG Lite 구조를 사용합니다. 생성 결과 검증은 pytest, scenario_sim, audit로 관리합니다.

## 5. 아키텍처 + 지침설계

전체 흐름은 화면, API, Director Agent, 하네스 지침, RAG/PKM, 기획안 생성, 저장과 검증 순서입니다. 하네스는 AI의 역할, 출력 형식, 평가 기준, 금지 조건을 정리한 지침 구조입니다. 브랜드 방향, 타깃, 후킹 시스템, 시청 유지 구조, 씬 구성을 슬롯처럼 나누고 AI가 그 슬롯을 채우도록 설계했습니다.

## 6. 현재 진행 상황 + 데모

현재 Next.js 주요 화면, FastAPI 생성 API, User-Brand-Domain-Series-Video 계층 구조, realuse 프로파일, 실제 LLM과 Supabase 연결, 기획안 생성과 plans 테이블 저장 검증까지 진행했습니다. 데모 영상에서는 짧은 아이디어 입력 후 AI가 브랜드와 타깃 기준을 정리하고 영상 기획안 후보를 생성하는 흐름을 30초로 보여줍니다.

## 7. 남은 일정

13주차에는 데모 흐름 고정과 UI 보강을 진행합니다. 14주차에는 예외 처리, Q&A 답변, 테스트와 회고 자료를 정리합니다. 15주차에는 최종 발표용 PPT, 시연 영상, 실행 가이드를 패키징합니다. 최종 목표는 새 기능 추가보다 첫 사용자 루프 안정화입니다.
