# Contract Change Proposal: Critic deprecated 0–5 Full 제거 (canonical-only)

- 제안일: 2026-05-31
- 제안자: Claude (Phase 9.5 Slice 4 sub-agent)
- 대상 contract: `docs/contracts/output_schema.md` §9 + `docs/contracts/agent_io_contract.md` §5 + `docs/contracts/db_schema.md` critic_evaluation
- 변경 종류: 삭제 (deprecated 필드 제거) — backward-compat 영향은 extra='ignore' + eval baseline 으로 흡수
- 긴급도: 보통

## 변경 사유

Phase 6 ADR-018 이 CriticEvaluation canonical(overall_score 0–1 + dimensions) 을 선언하면서 deprecated 0–5
필드(scores / overall_score_avg / eight_dim_scores) 를 "Phase 9+ eval 후 제거" 로 명시했다. Phase 9 wiring
(ADR-032) 으로 canonical 이 항상 populated 되어 deprecated fallback 은 dead code 가 됐고, Phase 9.5 Slice 2~3
에서 canonical-only eval baseline (schema 100% / pass 100%) 을 확보했다. ADR-034 결정에 따라 deprecated 0–5
를 Full 제거한다. run_critic 의 0–5 출력(LLM-facing)은 P-007 prompt contract 로 불변(NG3).

## 변경 내용 (before/after)

### output_schema.md §9
- §9.1 Body 스키마: deprecated `scores` / `overall_score_avg` 필드 제거 (canonical overall_score / dimensions 만).
- §9.1.2: "Deprecated 필드 (Phase 9+ eval 후 제거)" → "Phase 9.5 ADR-034 제거 완료" 로 갱신.
- §9.4 select_best_plan_index 우선순위: deprecated 3~5 단계(overall_score_avg / scores / eight_dim_scores
  + DeprecationWarning) 제거 → canonical 2 단계만.

### agent_io_contract.md §5
- Critic canonical-only 명시. run_critic 0–5 출력은 P-007 LLM-facing 으로 유지 + normalize_to_canonical
  (0–5→0–1) 이 canonical 생성 단일 경로임을 명시.

### db_schema.md critic_evaluation
- critic_evaluation JSONB 매핑에서 deprecated 0–5 필드 제거 note 추가.
