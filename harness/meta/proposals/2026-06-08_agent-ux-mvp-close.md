## 0. 브리프 핵심 (요지)

- 첫 화면 = 큰 입력창 + **4가지 상황 버튼** + 흐름 표시 (기능 나열 X, 아이디어 시작점).
- **전문 용어 노출 금지** — 내부 Brand/Domain/Series/PKM → "어떻게 기억되면 / 내 brain" 등으로 번역.
- 아키네이터식 1질문/화면 + **진행 누적 요약** 패널.
- 저장 후 **Brain 진입 CTA** → "내 생각이 쌓인다"는 락인.
- 영상 제작/편집/자동업로드/만능워크스페이스 아님 — 영상기획 전용 에이전트.

## 2. 라이브 테스트 발견(사용자 지적 3건)

1. **🐛 Discovery 안 넘어감**: `/new/discovery/step/1`에서 카드 선택해도 다음으로 못 감. 원인 추정 = "다음 단계로 ▶" CTA가 **Phase27 AppShell 하단 고정 네비에 가려짐**(또는 fold 아래). → 즉시 수정 대상.
2. **진입 중복**: 홈의 "마법사로 기획하기" vs "주제부터 찾기"가 헷갈림(Discovery가 이미 브랜드 방향을 다룸). → 브리프의 **4 상황 버튼**으로 교체하면 자연 해소(상황→적절 흐름 라우팅).
3. **에이전트 느낌 부족**: 지금은 폼·도구 느낌. → 진행 메시지·대화형·"내 brain 반영됨" 가시화.

## 3. 제안 — Phase 29: 에이전트 UX 마감 (슬라이스)

> 전부 기존 route/API/state 재사용 + gated/additive + 모바일 우선 + 회귀 0 원칙. 신규 제품기능 0.

- **S0 Discovery CTA 가림 버그 수정** (즉시): 위저드/플로우 페이지가 AppShell(fixed bottom)에 안 가리게(하단 패딩/CTA sticky 정리). 또는 위저드 전체화면에선 AppShell 숨김. → 막힌 흐름부터 뚫기.
- **S1 랜딩 재구성 + 4 상황 버튼**: 홈 = 슬로건("막막한 아이디어를, 실행 가능한 영상기획으로") + 큰 입력창 + **4 상황 버튼** + 흐름 표시(아이디어→기억될 이미지→SNS→영상기획안). 현 2 진입카드 교체.
  - 라우팅: 아이디어 정리 안 됨 → discovery / 브랜드 방향 → branding / SNS 반응 → branding(goal=sns) / 바로 기획안 → quick. (기존 route 우선.)
- **S2 용어 번역 (jargon 제거)**: UI 문구를 브리프 §3/§19 매핑대로 — 도메인·시리즈·브랜드·PKM 등 → 쉬운 말. (내부 코드/스키마 불변, 표시 문자열만.)
- **S3 아키네이터 진행 요약 패널**: 질문 흐름에 "현재 정리된 방향"(아이디어/기억이미지/타깃/톤…) 누적 표시 — 브랜딩 세션·Discovery 공통.
- **S4 저장 후 Brain CTA + 네비 보강**: 저장/선택 후 [내 brain에서 보기]/[같은 방향 새 영상]/[SNS 콘텐츠(준비중 비활성)] CTA. AppShell에 "저장한 기획안" 추가.
- **S5 에이전트 느낌**: 생성 중 단계별 진행 메시지(기존 SSE 활용) + 대화형 톤 + 결과에 "내 brain이 반영됨/이번에 학습됨" 표시. (Phase28 S3 "내 컨셉 수렴"과 연결 — 강화된 선호를 상단에.)

## 4. 범위 밖 (브리프 §16 / §10.4 동의)

SNS 자동완성·니즈서치(외부데이터)·공유커뮤니티·팀협업·트렌드분석·영상 자동제작/편집/업로드·만능 워크스페이스·다국어·결제 → **1차 MVP 검증 후**. SNS 콘텐츠 파생/목표설정/공유링크/니즈가설 = 2차 MVP. (지금은 경험층 마감만.)

## 5. Acceptance (브리프 §18)

1. 신규/비로그인이 첫 화면에서 시작점을 이해 2. 4 상황버튼 전부 실 route 연결 3. 도움 없이 기획안 1개 생성 4. 3안 비교·1개 선택 5. 저장됨 6. 저장/피드백이 PKM 반영 7. 내 brain에서 누적 확인 8. 모바일 한 손 9. 전문용어 최소 10. 영상제작 도구로 오해 안 됨. + 회귀 0(pytest/typecheck/build).

## 6. Phase 28과의 관계

Phase 28(2nd brain 학습 루프) = 백엔드 학습(S1 저장연결✅ / S2 강화·정리✅ / S3 컨셉수렴 대기). Phase 29 = 경험층. **S3(내 컨셉 수렴)은 Phase 29 S5(에이전트 느낌·brain 가시화)와 합쳐 진행**하는 게 자연스러움 → 사용자가 "쓸수록 맞춰진다"를 화면에서 체감.

## 7. 제안 진행 순서

S0(버그) → S1(랜딩·4버튼) → S2(용어) → S3(요약패널) → S4(Brain CTA) → S5(에이전트 느낌 + Phase28 S3 컨셉). S0~S2가 "발견·진입"의 80% — 먼저.
