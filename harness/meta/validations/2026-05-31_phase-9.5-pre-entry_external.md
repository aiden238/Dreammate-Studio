### 외부 LLM에 물을 질문 (V1~V7)

1. **V1 eval mock-deterministic primary**:
   - golden_set 회귀 runner 를 실 LLM 미호출 mock-deterministic(결정적 fixture/seed) primary 로 구축하고 실 LLM 은 mode flag + 문서로 두는 것(사용자 결정)이 CI 가능성·비용·회귀 baseline 신뢰성에 합리적인가?
   - mock-deterministic 이 schema/structural 회귀만 대리하고 "의미 품질"을 대리 못 하는 한계(U2)를 실 LLM mode 로 보완하는 경계가 적절한가?

2. **V2 golden_set markdown → 구조화 파싱**:
   - golden_set.md 의 GS-XXX YAML 블록을 loader 가 `{id, input, expected_properties}` 로 파싱하고 golden_set.md 를 단일 출처(케이스 정의 X)로 유지하는 것이 옳은가?
   - validation 규칙 중 자동 매칭 가능 항목(길이/배열/정확 매칭)과 LLM-as-judge 항목을 분리(자동 mock / 실 LLM mode)하는 것이 적절한가?
   - 케이스 수를 11 그대로 유지(NG10 — 확대 Phase 10+)하는 것이 baseline 구축에 충분한가?

3. **V3 revise effect metric (mock)**:
   - revise loop 개선 효과를 revise attempt별 canonical overall_score(0–1) delta 로 측정(mock fixture)하는 것이 Phase 4.5 D6 해소에 정합한가?
   - mock 이 메커니즘/구조 회귀를 대리하고 실 effect 크기는 실 LLM mode(U5)로 미루는 경계가 옳은가?

4. **V4 Critic deprecated 제거 경계 (run_critic 0–5 불변)**:
   - 제거 대상을 select_best_plan_index deprecated fallback + CriticEvaluation Optional 0–5 필드로 한정하고 run_critic 0–5 출력(P-007 prompt contract NG3) + normalize_to_canonical 0–5→0–1 변환을 불변으로 두는 경계가 명확한가?
   - run_critic 0–5 산출 유지 + CriticEvaluation schema 0–5 제거(Pydantic extra='ignore'로 verdict 0–5 키 무시)가 모순 없이 회귀 0인가?

5. **V5 제거 순서 (eval → 검증 → 제거)**:
   - Slice 2~3 eval runner → canonical-only 품질 baseline → Slice 4 제거 순서(eval 없이 제거 금지)가 안전성에 합리적인가?
   - 의도된 baseline delta 를 test_critic deprecated-fallback pytest.warns 케이스(+ CriticEvaluation 0–5 compat)로 한정(Phase 8 Slice 4 패턴)하는 경계가 적절한가?

6. **V6 임계값 게이트 (eval-run §6)**:
   - schema 준수 100% / 평균 점수 하락 ≤ 0.3 / 광고 표현 ≤ 5% / 차단 단어 0% 를 mock-deterministic 으로 강제하는 것이 충분한가?
   - 비용/latency/다양성 임계값을 실 LLM mode(NG2)로 미루는 것이 적절한가?

7. **V7 frontend types CriticEvaluation deprecated 정합**:
   - backend CriticEvaluation 0–5 제거 시 frontend types.ts non-optional(scores/overall_score_avg) + page.tsx 0–5 렌더를 canonical 전환(inline wrapper, PlanCard·component_map 0줄)하는 정합이 회귀 0에 충분한가?
   - frontend 변경(types + page.tsx)을 본 phase scope 에 포함(필요 시)하는 것이 과도하지 않은가?
