> 위치: `knowledge/llm_wiki/hook_patterns.md`
> 적용: 모든 영상 유형 (shortform / branding / promo) 첫 3-5초
> 연계: `shortform_planning.md`, `eval/hook_eval.md`, `evaluation_criteria.md`

---

## 0. 정의

**Hook**: 영상의 첫 3-5초. 시청자가 다음 장면을 볼지 결정하는 구간.

```
숏폼 retention curve의 첫 절벽: 0-3초
일반적 이탈률: 첫 3초 10-30%

좋은 hook 기준:
  - 0-3초 retention ≥ 90%
  - 시청자가 "이거 뭐지?" 또는 "그래서?" 라고 즉시 반응
  - hook 패턴이 분류 가능 (재현성)
```

영상기획 AI Critic agent (P-007)가 `hook_quality` 차원으로 평가.

---

## 1. 5대 분류

```
1. 질문형 (question)        — 호기심
2. 충격형 (shock)           — 의외성
3. 약속형 (promise)         — 가치 제시
4. 공감형 (empathy)         — 페인 포인트
5. 데모형 (demo)            — 즉시 보여주기
```

각 분류는 영상 유형에 따라 효과 차이.

---

## 2. 질문형 Hook (Question)

### 2.1 정의

시청자에게 직접 질문을 던져 호기심 유발. 답을 찾으려 시청 유지.

### 2.2 하위 분류

```
열린 질문:
  "왜 ____ 는 ____ 일까?"
  "____ 하면 어떻게 될까?"
  특징: 답이 명확하지 않음 → 강한 호기심
  주의: 너무 일반적이면 무시 ("일이 안 풀릴 때?" X)

닫힌 질문:
  "____ 알고 계셨어요?"
  "이거 해봤어요?"
  특징: yes/no 답이 가능 → 시청자 자기 확인
  주의: 자명한 질문은 효과 ↓

수사적 질문:
  "당신은 ____ 한 사람인가요?"
  "혹시 ____ 때문에 ____ 인가요?"
  특징: 답을 영상이 제공 → 영상에 의존 유도
```

### 2.3 효과적 사례

```
"왜 ____ 는 30대에 ____ 할까?"
"이거 알고 계셨어요? ____ 가 ____ 라는 거"
"오늘 ____ 한 분, 손!"
```

### 2.4 적합 영상 유형

- shortform_planning: 강력
- promo_video: 보통 (페인 포인트 질문이 더 효과적)
- branding_video: 약함 (가치 진술이 더 적합)

---

## 3. 충격형 Hook (Shock)

### 3.1 정의

의외 / 반전 / 통계 / 충격적 사실로 시청자 정지.

### 3.2 하위 분류

```
반전:
  "____ 가 사라졌어요"
  "그동안 ____ 잘못 알고 있었습니다"
  특징: 기존 인식 깨기

통계:
  "100명 중 ____ 명이 ____"
  "____ 의 ____%가 ____"
  특징: 숫자 + 의외성 결합

의외:
  "이게 ____ 인 거 아세요?"
  "____ 분 만에 ____ 했어요"
  특징: 예상 벗어남
```

### 3.3 효과적 사례

```
"____년 동안 ____ 안 했더니"
"한국 사람 중 ____% 모르는 ____"
"____원으로 만든 ____ 입니다"
```

### 3.4 주의

```
- 광고 단어 위험: "100%", "절대" 사용 시 1차 차단
- 과장된 충격: 시청자 알아채면 신뢰도 ↓
- 클릭베이트: 영상 본문이 hook 약속 못 채우면 dislike ↑
```

### 3.5 적합 영상 유형

- shortform_planning: 매우 강력 (조회수 ↑)
- promo_video: 강력 (단 정직성 유지)
- branding_video: 약함 (브랜드 톤에 안 맞을 수 있음)

---

## 4. 약속형 Hook (Promise)

### 4.1 정의

영상 시청 후 얻을 가치 / 해결 / 정보를 미리 제시.

### 4.2 하위 분류

```
이득:
  "30초 안에 ____ 알려드릴게요"
  "____ 하면 ____ 됩니다"
  특징: 명확한 보상

해결:
  "____ 고민 해결됩니다"
  "이 영상 보면 ____ 안 됩니다"
  특징: 페인 포인트 → 해결

비밀:
  "잘 안 알려진 ____"
  "전문가만 아는 ____"
  특징: 희소성 / 우월감
```

### 4.3 효과적 사례

```
"30초로 ____ 마스터하기"
"____ 안 사도 되는 이유"
"전문가가 절대 안 알려주는 ____"
```

### 4.4 주의

```
- 약속 못 지키면 retention curve 급락 (Reveal에서 이탈)
- 너무 큰 약속: "1주일 만에 부자 되는 법" → 신뢰 ↓
```

### 4.5 적합 영상 유형

- shortform_planning: 매우 강력 (특히 tutorial 포맷)
- promo_video: 강력 (해결 약속 = 제품 효과)
- branding_video: 보통 (가치 약속 가능)

---

## 5. 공감형 Hook (Empathy)

### 5.1 정의

시청자의 페인 포인트 / 일상 관찰을 정확히 짚어 "내 얘기다" 라고 느끼게 함.

### 5.2 하위 분류

```
페인 포인트:
  "____ 때문에 ____ 인 분?"
  "____ 인데 ____ 하기 힘들죠"
  특징: 특정 고민/불편 명시

일상 관찰:
  "____ 할 때 이런 적 있죠"
  "____ 인 사람 손?"
  특징: 시청자가 인지 못 한 일상 패턴

세대/연령 공감:
  "30대 ____ 만 아는 ____"
  "엄마들 다 그러죠"
  특징: 특정 그룹 정체성
```

### 5.3 효과적 사례

```
"퇴근 후 ____ 할 시간 없으시죠"
"____ 살에 ____ 인 분, 손!"
"____ 처음 시작할 때 이런 거 다 했죠"
```

### 5.4 주의

```
- 부정확한 일반화: "모든 30대는 ____" → 반발
- 너무 좁은 페인: 타겟 외 사용자 이탈
```

### 5.5 적합 영상 유형

- shortform_planning: 강력
- promo_video: 매우 강력 (페인 → 해결 = 표준 구조)
- branding_video: 강력 (시청자 연결)

---

## 6. 데모형 Hook (Demo)

### 6.1 정의

말 대신 즉시 보여주기. 첫 3초에 액션 / 결과 / 변화.

### 6.2 하위 분류

```
즉시 결과:
  Hook = 완성품 또는 마지막 장면
  특징: 호기심 자동 발생 ("어떻게 저렇게?")

변화 보여주기 (before/after):
  Hook = before 0.5초 + after 1초
  특징: 차이가 강력하면 시청 유지

과정 일부:
  Hook = 과정 중간의 신기한 순간
  특징: 시청자가 "전체 흐름 보고 싶어짐"
```

### 6.3 효과적 사례

```
[화면] 0-1초: 빵 반죽 / 1-2초: 오븐 / 2-3초: 완성품
[화면] 0-1초: 흰 종이 / 1-2초: 그림 그리기 / 2-3초: 완성 그림
[화면] 0-2초: 어수선한 방 / 2-3초: 정리된 방 (jump cut)
```

### 6.4 주의

```
- 텍스트 hook 없이 영상만으로 → 일부 시청자에게 맥락 부족
- 권장: 영상 + 짧은 자막 1줄 (3-5단어)
```

### 6.5 적합 영상 유형

- shortform_planning: 매우 강력 (TikTok에서 특히)
- promo_video: 강력 (제품 데모)
- branding_video: 강력 (상징 장면 데모)

## 7. 분류 매트릭스 (영상 유형 × Hook 분류)

| | shortform | promo | branding |
|---|---|---|---|
| 질문형 | 강력 | 보통 | 약함 |
| 충격형 | 매우강력 | 강력 | 약함 |
| 약속형 | 매우강력 | 강력 | 보통 |
| 공감형 | 강력 | 매우강력 | 강력 |
| 데모형 | 매우강력 | 강력 | 강력 |

영상기획 AI가 카드 생성 시 사용자가 선택한 영상 유형 + hook 분류 조합으로 매트릭스 활용.

## 8. 광고 단어 회피 (Hook 특수 주의)

Hook은 광고 단어가 가장 자주 들어가는 위치:

```
1차 차단 (Critic reject):
  "최고의 ____" → "사람들이 ____ 한"
  "100% 효과 ____" → "____% 효과 (구체 숫자)"
  "완벽한 ____" → "충분한 ____"
  "절대 후회 X" → "____ 한 분 ____% 가 ____"

2차 경고:
  "놓치지 마세요" → "이번 ____ 까지만"
  "마지막 기회" → 가능하면 제거
```

## 9. 사용 빈도 / 효과 평균 (Phase 4+ 데이터 기반 보강)

현재 추정 (정량 데이터는 Phase 4+ 사용자 데이터 누적 후 갱신):

```
Hook 분류별 사용 빈도 (예상):
  공감형: 30% (가장 자주)
  데모형: 25%
  약속형: 20%
  질문형: 15%
  충격형: 10%

Hook 분류별 평균 retention 0-3초 (예상):
  데모형: 92%
  충격형: 90%
  공감형: 88%
  약속형: 85%
  질문형: 80%

도메인별 차이 (Phase 4+):
  음식: 데모형 효과 ↑
  교육: 약속형 효과 ↑
  의료: 공감형 효과 ↑
  패션: 충격형 + 데모형
```

## 10. Phase 4+ 보강 예정 항목

```
- 실제 사용자 데이터 기반 빈도/효과 정량화
- 도메인별 hook 효과 차이 (음식 vs 교육 vs 의료 등)
- 플랫폼별 hook 차이 (TikTok vs Shorts vs Reels)
- 한국어 vs 영어 hook 패턴 비교
- AI 생성 hook의 자체 평가 (LLM 기반 hook quality 평가)
- hook 길이 (3초 vs 5초) 효과 차이
- 음악/사운드 효과와 hook 결합
- 텍스트 hook vs 음성 hook 비교
```

## 11. 실패 패턴 (회피 대상)

```
1. 너무 일반적: "오늘은 ____ 에 대해" → 정보 약속 없음
2. 너무 길음: 5초 넘는 hook → retention 급락
3. 정적 화면: 움직임 없는 단순 텍스트 → TikTok에서 즉시 이탈
4. 광고 단어 남발: 첫 줄에 "최고", "100%" → 알고리즘 페널티
5. 거짓 약속: hook과 본문 불일치 → dislike ↑
6. 클리셰: 누구나 쓰는 표현 → 차별성 ↓
7. 시청자 부재: "오늘 영상은 ____" (자기소개만) → 즉시 이탈
```

영상기획 AI Critic이 8차원 평가 중 `hook_quality` 차원에서 회피 패턴 자동 점검.
