## 0. 정의

**프로모션 영상**: 특정 **제품 / 서비스 / 이벤트 / 캠페인**의 인지 + 행동 유도가 목적인 영상.

```
구분:
  branding_video    = 정체성 (장기 신뢰)
  promo_video       = 특정 대상 홍보 (단기 행동)
  shortform_planning = 형식 (길이/플랫폼)

영상기획 AI 적용:
  structure_type: promo
  approach_label: problem_solution | testimonial | demo | offer
```

## 1. 표준 구조: 문제 → 공감 → 소개 → 장점 → CTA

```
0-5s   문제 제기 (Hook)
  - "____ 때문에 고민이신가요?"
  - 시청자가 즉시 "내 얘기다" 라고 느끼도록

5-15s  대상 공감 (Tension 확장)
  - 그 문제로 인한 일상 불편 / 비용 / 시간 손실
  - 페인 포인트 시각화

15-30s 제품/서비스 소개 (Reveal)
  - "____ 이 해결합니다"
  - 핵심 기능 1-2개 (모든 기능 X)

30-45s 장점 / 차별점 (Strengthen)
  - 다른 대안 대비 차별점
  - 사용자 후기 / 데이터 / 데모

45-60s CTA (Action)
  - 구매 / 가입 / 방문 / 공유
  - 명확한 다음 행동 1개
```

길이 가이드: 숏폼 30-60초 / 미드폼 1-2분 / 롱폼 3-5분 (Phase 4+).

## 2. 광고 단어 회피 (강제 적용)

`output_schema.md §14` ad_phrase_blocklist 정합. 프로모션 영상은 광고 단어가 가장 많이 나오는 유형 — **강제 차단 필수**.

### 2.1 1차 차단 (Critic agent reject)

```
"최저가"      → rejected
"무조건"      → rejected
"100%"        → rejected
"완벽한"      → rejected
"최고의"      → rejected
"절대"        → rejected
"보장"        → rejected
"단언"        → rejected
```

### 2.2 2차 경고 (warning만)

```
"놓치지 마세요"  → warning
"지금 바로"      → warning
"마지막 기회"    → warning
"후회 없는"      → warning
```

### 2.3 대체 표현 예시

| 광고 단어 | 권장 대체 |
|---|---|
| 최저가 | "합리적인 가격" / "____원 부터" |
| 100% 효과 | "많은 분이 효과 보셨어요" / 구체 데이터 |
| 완벽한 솔루션 | "충분히 ____한" / "여러 상황에 맞는" |
| 절대 후회 없음 | "사용자 만족도 ___%" / 후기 인용 |
| 최고의 품질 | "엄선된" / 구체 차별점 |
| 보장 | "약속" / "정책으로 보장" |
| 놓치지 마세요 | "이번 ____ 까지" |

## 3. CTA 패턴 분류

### 3.1 구매형 CTA

```
- "지금 ____ 에서 만나보세요"
- "프로필 링크에서 구매 가능"
- "____원, ____ 에서"

조건:
  - 가격 명시 권장
  - 구매 채널 1개만 (산만하지 않게)
  - 한정 조건 시 가짜 긴급 회피 ("마감 임박" 남발 X)
```

### 3.2 가입형 CTA

```
- "____ 가입하고 ____ 받으세요"
- "프로필 링크에서 무료 가입"
- "회원 전용 ____ 받기"

조건:
  - 가입 후 혜택 명확
  - 회원가입 절차 짧음 강조 (1분, 클릭 3번 등)
```

### 3.3 방문형 CTA (오프라인 매장)

```
- "____ 동 ____ 거리, ____ 시간에 만나요"
- "주소: ____ 영업: ____"

조건:
  - 위치 + 시간 필수
  - 주차/접근성 정보 권장
```

### 3.4 공유형 CTA

```
- "____ 친구한테 알려주세요"
- "이 영상 공유하면 ____"
- "댓글로 ____ 알려주세요"

조건:
  - 공유 동기 부여
  - 인센티브 (이벤트 등) 가능
```

## 4. 시즌별 변주

### 4.1 신학기 (3월, 9월)

```
타겟: 학부모 / 학생 / 신입사원
패턴: "새로운 시작에 ____" / "____ 학기 준비"
강조: 가성비 / 일상 변화
```

### 4.2 블랙프라이데이 / 광군절 (11월)

```
타겟: 쇼핑 욕구 강한 시기
패턴: 할인폭 강조 / 한정 수량
주의: 가짜 긴급 ("마지막 1개" 남발 시 광고 단어 위험)
```

### 4.3 연말연시 (12-1월)

```
타겟: 선물 수요 / 자기 보상
패턴: "올해의 마지막 ____" / "새해 ____"
강조: 의미 있는 선물 / 회고
```

### 4.4 봄/여름/가을/겨울 시즌

```
계절성 강한 제품 (의류 / 음식 / 여행):
  - 시즌 키워드 활용
  - 다음 시즌 대비 (1-2개월 전 광고)
```

영상기획 AI는 brand_memory에 사용자 시즌 패턴 누적 → 추천 시 반영 (Phase 4+).

## 5. 사례 시드 (5-7 예시)

### 5.1 신제품 출시 (캐주얼)

```
Hook: "이거 진짜 신기해요"
Tension: 일상에서 자주 만나는 작은 불편
Reveal: 신제품 등장 + 데모 (5초)
Strengthen: "____ 분이 이미 써보셨어요"
CTA: "프로필 링크에서, ____원부터"
```

### 5.2 카페 신메뉴 (캐주얼 친근)

```
Hook: "오늘 새로 나온 ____"
Tension: 만드는 과정 / 재료
Reveal: 완성 + 한 입
Strengthen: "____ 하루 ____잔만"
CTA: "____ 동 ____ 카페에서"
```

### 5.3 온라인 강의 (전문)

```
Hook: "____ 배우기 시작했는데 막막한 분들"
Tension: 자료 흩어짐 / 어디부터 / 비용 부담
Reveal: 강의 소개 + 커리큘럼 1줄
Strengthen: 수강생 후기 1개
CTA: "____원, ____ 일까지 ____% 할인"
```

### 5.4 의류 브랜드 세일 (캐주얼 playful)

```
Hook: "____ 옷 사서 안 입은 거 많죠?"
Tension: 옷장 정리 / 가격 부담
Reveal: 시즌 세일 + 베스트셀러 보여주기
Strengthen: "사이즈별 ____벌 입어봄"
CTA: "____월 ____일까지, 프로필 링크"
```

### 5.5 식당 오픈 이벤트 (캐주얼 친근)

```
Hook: "____ 동에 새로 생긴 ____ 집"
Tension: 동네 분들 / 음식 모습
Reveal: 메뉴 / 가격 / 위치
Strengthen: "____월 ____ 일 오픈, 첫 손님 ____ 명에게 ____ 증정"
CTA: "주소 ____ / 오픈 시간 ____"
```

### 5.6 앱 다운로드 유도 (캐주얼 + 전문)

```
Hook: "스마트폰에 ____ 앱 없으세요?"
Tension: 그 앱이 해결하는 일상 문제
Reveal: 앱 화면 시연 (10초)
Strengthen: 다운로드 수 / 평점
CTA: "____ 스토어에서 ____ 검색"
```

### 5.7 부동산 / 인테리어 (정중)

```
Hook: "이 집, ____ 평인데 이렇게 넓어 보이는 이유"
Tension: 일반 평면 / 답답함
Reveal: 인테리어 디자인 차이
Strengthen: "____ 회사, ____년 경력"
CTA: "상담 문의: ____"
```

## 6. 신뢰도 신호 (광고임에도 효과 ↑)

광고 단어 회피 + 다음 신호 추가:

```yaml
구체 데이터:
  - "____ 만 분이 사용 중"  (정확한 숫자)
  - "____% 재구매율"

사용자 후기:
  - 실제 인용 (가짜 후기 금지)
  - 동영상 후기 (가능 시)

투명성:
  - 제작 과정 공개
  - 단점도 솔직히 언급 (소량)

브랜드 일관성:
  - 이전 영상과 톤 일치
  - 약속 이행 (이전 약속 인용)
```

영상기획 AI가 Critic에서 brand_safety + brand_consistency 점검.

## 8. 실패 패턴 (회피 대상)

```
1. 광고 단어 남발 ("최고", "100%", "보장") → CTR ↓, 알고리즘 페널티
2. CTA 없음 (홍보인데 다음 행동 모름)
3. 가격/조건 모호 ("문의 주세요" 만)
4. 가짜 긴급 ("마지막 1개" 매주 반복)
5. 자랑 일색 (시청자 페인 포인트 없이 우리 제품만)
6. 정보 과부하 (1 영상에 5개 제품 / 10개 기능)
7. 가짜 후기 (사용자가 즉시 알아챔)
```
