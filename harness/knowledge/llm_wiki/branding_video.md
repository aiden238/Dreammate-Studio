## 0. 정의

**브랜드 영상**: 특정 제품/이벤트 홍보가 아닌, **브랜드 자체의 정체성 / 가치 / 세계관**을 전달하는 영상.

```
구분:
  branding_video    = 브랜드 자체 (정체성/가치)
  promo_video       = 특정 상품/이벤트 (판매/참여)
  shortform_planning = 형식 (길이/플랫폼)

영상기획 AI 적용:
  structure_type: branding
  approach_label: narrative | testimonial | identity_statement
```

## 1. 4계층 데이터 모델 활용

영상기획 AI 에이전트의 핵심: **Brand → Domain → Series → Video Project** 4계층 정합.

```
Brand:    "햇살베이커리" (가게 정체성)
  ↓
Domain:   "동네 사람들의 작은 행복"
  ↓
Series:   "오늘의 빵 일기" (정기 시리즈)
  ↓
Video:    개별 영상기획 1건
```

브랜드 영상은 **Brand 또는 Domain 레이어 자체를 다루는 영상**. Series 단위가 아닌 단발성 또는 분기성.

### 1.1 브랜드 영상의 위치

```
1. Brand 시작 시: "안녕하세요, 햇살베이커리입니다" (오프닝)
2. Domain 전환 시: "오늘부터 ____ 시리즈를 시작합니다"
3. 가치관 강조 시: "왜 우리가 ____ 하는지" (분기적, 신뢰 누적)
4. 위기/공지 시: "이런 일이 있었습니다" (투명성)
```

## 2. 표준 구조: 가치 → 상징 → 연결

```
Phase 1 (0-15초)  가치 진술
  - "우리는 ____ 한 사람들입니다"
  - 브랜드의 핵심 신념 1문장

Phase 2 (15-40초) 상징 장면
  - 그 가치를 보여주는 구체적 장면
  - 추상이 아닌 손에 잡히는 디테일
  - 사람 / 공간 / 행동

Phase 3 (40-60초) 사용자 연결
  - "당신은 ____ 한 사람입니까?"
  - 또는: "함께 ____ 합시다"
  - 시청자를 브랜드 세계관에 초대

Phase 4 (60-75초) 기억할 문장
  - 짧고 강력한 한 줄
  - 브랜드명 + 핵심 약속
  - 영상 종료 후 잔상으로 남는 문장
```

### 2.1 길이 가이드

```
숏폼 브랜드 영상: 30-60초 (위 4단계 압축)
미드폼: 1-3분 (각 단계 확장)
롱폼 (mini-doc): 3-10분 (Phase 4+ MVP 범위 외)
```

## 3. 브랜드 일관성 평가 차원

`eval/brand_consistency_eval.md` 정합. Critic agent (P-007)가 평가:

### 3.1 5차원 일관성

```yaml
tone:
  설명: 정중 / 친근 / 전문 / 캐주얼 / 따뜻 등
  체크: brand_memory.tone_profile과 일치?

vocabulary:
  설명: 자주 쓰는 용어 / 회피하는 단어
  체크: brand_memory.vocabulary 준수?

visual_implication:
  설명: 텍스트로 표현된 시각 디테일 (실제 촬영은 사용자 몫)
  체크: 브랜드 컬러 / 분위기 일관?

value_alignment:
  설명: 영상 메시지가 브랜드 가치와 정합?
  체크: domain 가치관과 충돌 없음?

format_consistency:
  설명: 시리즈 내 포맷 통일성
  체크: 이전 영상들과 구조 유사?
```

각 차원 0-5점 평가.

## 4. 톤앤매너 4가지 표준

영상기획 AI가 사용자 brand 분석 시 4가지 톤 중 1개 분류:

### 4.1 정중 (formal)

```
특징: 존댓말 일관 / 격식 / 신뢰감
적합: 금융 / 의료 / 법률 / B2B
예시 어휘: "고객님" / "안내드립니다" / "최선을 다하겠습니다"
회피: 줄임말 / 이모지 / 비속어
```

### 4.2 친근 (casual_friendly)

```
특징: 반말 또는 부드러운 존댓말 / 일상 어조
적합: 가족 비즈니스 / 동네 가게 / 라이프스타일
예시 어휘: "여러분~" / "오늘은 말이죠" / "한번 같이 봐요"
회피: 너무 격식 / 차가운 어조
```

### 4.3 전문 (expert)

```
특징: 정확한 용어 / 데이터 / 근거 제시
적합: 교육 / 기술 / 컨설팅
예시 어휘: "연구에 따르면" / "구체적으로" / "이유는"
회피: 모호한 표현 / 감정 과잉
```

### 4.4 캐주얼 (casual_playful)

```
특징: 짧은 문장 / 유머 / 트렌드 활용
적합: 10-20대 타겟 / 패션 / 음식 / 게임
예시 어휘: "이거 실화?" / "ㄹㅇㅋㅋ" / "찐"
회피: 너무 진지 / 정보 과부하
```

영상기획 AI는 brand_memory에서 톤 추출 후 모든 카드/plan에 일관 적용. Phase 0+ MOA Lite에서 Critic이 톤 일치 검증.

## 5. 사례 시드 (5-7 예시)

Phase 1 RAG external_seed로 사용:

### 5.1 동네 빵집 브랜드 영상 (캐주얼 친근)

```
Hook: "오늘 새벽 4시, 우리 빵집에서는"
Tension: 반죽하는 손 / 오븐의 빛 / 잠 못 자는 표정
Reveal: "이렇게 만든 빵이, 누군가의 아침이 됩니다"
CTA: "당신의 아침을 채우러 오세요"
```

### 5.2 운동복 브랜드 (전문 + 약간 캐주얼)

```
Hook: "운동복은 단순한 천이 아닙니다"
Tension: 사용자 클로즈업 / 땀 / 호흡
Reveal: "당신의 한계와 함께 늘어나는 옷"
CTA: "____ (브랜드명), 함께 달려요"
```

### 5.3 의료 클리닉 (정중 + 따뜻)

```
Hook: "환자 한 분 한 분의 이야기를 듣는 일"
Tension: 진료실 풍경 / 의사의 메모 / 환자 미소
Reveal: "____ (클리닉명) 가 가장 중요하게 여기는 것입니다"
CTA: "당신의 건강한 일상을 위해"
```

### 5.4 카페 브랜드 (캐주얼 친근)

```
Hook: "왜 우리는 매일 커피를 마실까?"
Tension: 컵에 손이 닿는 순간 / 향 / 햇살
Reveal: "잠깐의 멈춤이 필요해서"
CTA: "오늘의 한 잔, ____ 에서"
```

### 5.5 IT 스타트업 (전문 + 캐주얼)

```
Hook: "____ 가 처음 만든 도구는 우리 팀이 쓰던 것입니다"
Tension: 코딩 화면 / 회의 / 새벽 슬랙
Reveal: "그래서 우리는 사용자 입장을 압니다"
CTA: "함께 만들고 싶다면, ____ 로 오세요"
```

### 5.6 패션 브랜드 (캐주얼 playful)

```
Hook: "오늘 뭐 입지 고민하는 당신에게"
Tension: 옷장 / 거울 / 망설임
Reveal: "____ 한 벌이면 끝"
CTA: "더 많은 룩, 프로필 링크"
```

### 5.7 비영리/공익 (정중 + 따뜻)

```
Hook: "한 사람의 도움이 누군가의 1년을 바꿉니다"
Tension: 현장 사진 / 활동가 / 수혜자
Reveal: "____ (단체명) 가 11년째 해온 일입니다"
CTA: "함께 하려면, 링크에서"
```

## 6. brand_memory 자동 추출 (P-AUX-2)

영상기획 AI가 사용자 영상기획안 누적 시 brand_memory 자동 추출:

```yaml
추출 대상:
  - 사용자가 like 한 hook 패턴 → tone_profile
  - 자주 쓰는 어휘 → vocabulary
  - 거절한 카드 패턴 → avoid_patterns
  - 선택한 structure_type 비율 → format_preference

Critic agent 활용:
  - 새 plan 생성 시 brand_memory 일관성 평가
  - 일관성 깨면 revise 권고 (max 2회)
```

자세한 절차는 `ai_system/prompts/prompt_registry.md` P-AUX-2 참조.

## 7. 광고 단어 회피 (브랜드 영상 특수)

브랜드 영상은 홍보보다 정체성 전달이 목적. 광고 단어가 들어가면 신뢰도 ↓:

```
회피 (1차 차단):
  - "최고의" → "우리가 믿는"
  - "완벽한" → "정직한"
  - "100%" → "변함없이"
  - "보장" → "약속"

권장:
  - "함께" / "오래" / "정직한" / "꾸준히"
  - "당신" 보다 "여러분" / "같이"
```

## 9. 실패 패턴 (회피 대상)

```
1. 일관성 결여 (영상마다 다른 톤)

3. 광고적 표현 ("최고의" 남발)
4. 모방 (다른 브랜드 톤 copy)
5. 자기 자랑 (we ____ , we ____ 반복)
6. 시청자 부재 (브랜드만 말함)
7. 너무 짧은 가치 진술 + 너무 긴 자랑 (균형 깨짐)
```
