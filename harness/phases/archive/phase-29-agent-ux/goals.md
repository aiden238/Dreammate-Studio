# Phase 29 — 에이전트 UX 마감 (goals)

## 한 줄 정의

"기능이 없는 게 아니라 **사용자가 기능까지 도달 못 하는 게 문제**" — 랜딩·진입·용어·에이전트 느낌을 닫아 첫 사용자가 도움 없이 핵심 루프(아이디어→상황→질문→기획안→저장→내 brain)를 완주하게 만든다. 신규 제품기능 0, 경험층 마감.

> 근거: 사용자 UI/UX 브리프(`dreammate_studio_mvp_uiux_brief_for_claude_codex.md`) + 라이브 테스트 발견. 기획 초안 = `meta/proposals/2026-06-08_agent-ux-mvp-close.md`.

## 슬라이스

- **S0 Discovery CTA 가림 버그 수정** ✅: 위저드/플로우(`/new`, `/plan`)의 자체 고정 하단 CTA를 Phase27 AppShell(고정 네비, z-40)이 덮어 "다음/생성/저장"을 못 누름 → AppShell HIDDEN_PREFIXES 에 `/new`·`/plan` 추가(집중 플로우는 네비 숨김). 홈/`/brain`은 유지.
- **S1 랜딩 + 4 상황 버튼** ✅: 슬로건("막막한 아이디어를, 실행 가능한 영상기획으로") + 큰 입력창 + 4 상황 버튼(아이디어 정리/브랜드 방향/SNS 반응/바로 기획안) + 흐름 표시. 현 2 진입카드 교체. 전부 기존 route 재사용.
- **S2 용어 번역(jargon 제거)** ✅: Discovery 헤더(도메인/시리즈/타깃/톤 → "어떤 주제 영역/시리즈/누구에게/어떤 톤"), step1(브랜드 방향 → "어떻게 기억되면"), 직접입력 설명. 내부 코드/스키마 불변, 표시 문자열만.
- **S3 아키네이터 진행 요약 패널** (대기): 질문 흐름에 "현재 정리된 방향" 누적 표시.
- **S4 저장 후 Brain CTA + 네비 보강** (대기): 저장 후 [내 brain에서 보기]/[같은 방향 새 영상]/[SNS(준비중)].
- **S5 에이전트 느낌** (대기): 생성 진행 메시지 + "내 brain 반영됨" + Phase28 S3(내 컨셉 수렴) 결합.

## 통과 기준 (브리프 §18 요지)

신규/비로그인이 첫 화면에서 시작점 이해 + 4 상황버튼 전부 동작 + 도움 없이 기획안 1개 생성·선택·저장 + PKM 반영 + /brain 누적 확인 + 모바일 한 손 + 전문용어 최소 + 영상제작 도구 오해 0 + 회귀 0.
