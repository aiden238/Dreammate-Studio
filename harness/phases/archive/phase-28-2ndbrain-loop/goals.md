# Phase 28 — 2nd brain 학습 루프 (goals)

## 한 줄 정의 (= /GOAL 지향)

**"쓸수록 내 브랜드를 이해하는 영상기획 2nd brain"** — 모든 대화가 저장되고 피드백이 학습으로 이어지며, **반복되는 부분은 강화·불필요한 부분은 제거**되어 **나만의 컨셉**으로 수렴. 최근 LLM-wiki / 2nd-brain 에이전트 패턴.

> ★ 사용자 합의(2026-06-08): /GOAL을 한 번에 도달하는 게 아니라 **이번 기획의 방향 목표**로 삼아 단계적으로 빌드. 학습 신호 = **명시 피드백 + 암묵 신호 둘 다**(Option 1).

## 배경 (왜)

라이브 테스트에서 드러난 갭: 가장 눈에 띄는 **홈 입력이 막다른 길**(레거시 /generate → 저장 실패 + 피드백→학습 미연결)이라, 첫 사용자가 써도 brain에 아무것도 안 쌓였다(songbyeongcheol84 계정 0건 확인). PKM 루프(Phase 17)·/brain(19~26)·주입은 있으나 **"모든 대화 → 저장 → 강화/정리 → 컨셉"의 연결·정련**이 빠짐.

## 슬라이스 (단계적)

- **S1 모든 대화 저장 + 학습 연결** ✅: 홈도 plans 흐름(startPlan→/plan/[id])을 타게 → 저장(plans 영속)+auth+피드백 UI → 어느 경로로 써도 brain에 쌓임. (검증: 데모 e2e plans 0→1, pkm 0→2.)
- **S2 반복 강화 + 불필요 제거**: pkm `reinforce_count`/`last_reinforced_at` 추가 → 유사 재등장=강화·dedup, 모순=감점, 오래·미강화=decay/archive. 추출 품질 정련(한 reason→여러 entry 정확 분해, generic 노이즈 억제).
- **S3 나만의 컨셉 수렴**: 상위 강화 PKM → "내 컨셉" 합성·요약 → /brain 상단 + 생성 시 우선 주입.

## 통과 기준(요지)

어느 진입(홈/새 기획/주제찾기)으로 써도 → 저장 + 피드백→학습 → 반복 강화·불필요 정리 → "내 컨셉" 가시화. (S별 acceptance = acceptance.md)
