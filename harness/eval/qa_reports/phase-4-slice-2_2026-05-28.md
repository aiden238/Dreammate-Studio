## 6. parallel error graceful 검증

`test_parallel_partial_failure_graceful`:
- 3 plans 중 1개가 "(생성 실패 2)" fallback dict
- router는 그대로 schema 변환 (graceful — Plan model 통과)
- 최종 응답 length === 3 보장
- HTTP 200 유지 (사용자 차단 0건)

`run_planning_parallel_3` 내부 graceful 로직:
1. `asyncio.gather(*tasks, return_exceptions=True)` — 일부 실패 흡수
2. 실패한 인덱스만 1회 retry (`_run_planning_single` 재호출)
3. retry도 실패 시 `_fallback_plan_dict(i)` 반환 (length 3 보장)
4. approach_label unique 강제 (fallback pool에서 미사용 label 사용)

→ 사용자 응답은 어떤 실패에서도 length 3 또는 502 (모두 실패 시).
