## 3. ★ 결론

```
1. 일반 품질(generic) = commodity. 래퍼와 agent-grade 동급 (Δ flat). ← S1+S2 2회 확인.
2. 개인화 적합도(fit) = agent-grade 가 압도. 구속 PKM 주입 시 plan 이 실제로 브랜드 톤/잠금선호/
   시리즈 포맷을 따른다 (Δfit +0.425, 강하고 일관).
3. 주입 방식이 결정적: rag_context(S1, "복제금지 참고") → 효과 0 / binding 프리앰블(S2) → 큰 효과.
   ⇒ PKM 은 "참고"가 아니라 "구속 지시"로 넣어야 한다 (가/다 설계 직접 반영).
```

→ moat 리서치와 정합: 차별성은 generic 품질(commodity)이 아니라 **fit·일관성**이며, agent-grade
  구조(PKM 주입)가 이를 실제로 만들어낸다 — **메커니즘 검증됨**.

## 4. ★ 정직한 한계 (over-claim 방지)

```
A. 약한 순환성(tautology): judge 는 "plan 이 주입된 pack 을 반영했는가"를 본다. B 는 pack 을 받았고
   A 는 안 받았으니 B 가 높은 건 부분적으로 당연하다. → Δfit 이 증명하는 것은 **"주입 메커니즘이
   출력을 실제로 바꾼다"**(S1 에선 rag_context 가 못 바꿨음 — 이건 비자명) 이지, "fit=좋은 영상"이 아니다.
B. fit ≠ value: 브랜드에 맞는 plan 이 곧 더 좋은/유용한 plan 이라는 보장은 없다. 사용자가 창의적
   일탈을 선호할 수도. → fit→value 는 ★S3 사람 blind 로 확인해야 한다.
C. 시뮬 PKM: 실 누적 데이터 아님(§5.1). compounding(H2)·시장 moat 는 실사용 전제 — 미증명.
```
