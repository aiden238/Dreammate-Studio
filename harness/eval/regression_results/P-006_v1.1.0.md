## 3. 깊이(depth_actionability) 재측정 — S6 으로 이연 (실 LLM 필요)

- v1.1.0 rich 의 핵심 효과 = depth 0.231 → ≥0.8 (Phase 12 깊이 격차 4.3x 해소).
- depth_actionability 는 mock-deterministic 러너가 의미있게 채점 불가(CC-011) → **실 LLM(mode=real) 또는 human review 전용**.
- 따라서 rich 실측은 **S3(gated wiring) 후 S6** 에서 flag ON 라이브(키 user-provided)로 수행:
  `eval/regression_results/phase-13-*` (compact↔rich depth 대조 + 토큰 cost 재조정).

## 4. 활성 정책 (gated)

- v1.1.0: `rich_output_enabled` ON 경로 전용. flag default OFF(S3) → 운영 기본 = v1.0.0 (deactivate 안 함).
- flag ON 전환 = S6 depth ≥0.8 + 라이브 검증 통과 후 별도 결정.

## 5. 판정

- **S2 PASS (gated 등록)**: v1.1.0 rich 프롬프트 + 버전 등록 + schema 정합 + 런타임 불변(behavior-preserving) 확인.
