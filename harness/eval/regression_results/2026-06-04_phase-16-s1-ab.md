## 1. 설정

- Arm A (baseline): `run_planning_parallel_3(input, rag_context=[])` → 3 plans
- Arm B (agent-grade): `rag_context = pkm_pack_to_rag_context(CAFE_PERSONA)` = **8 entries 주입** (locked/personal/brand/series/trend/wiki)
- 입력: "동네 카페 신메뉴 원두를 소개하는 30초 쇼츠 1편을 기획해줘" (페르소나 pack 과 분리 — 정답 미주입)
- 채점: 각 plan run_critic(director 10차원) → overall_score 평균(0~1). reps=3 (노이즈 완화).
- ★ 통제 확인: Arm A rag_context=0 / Arm B=8 (주입 실제 작동). 단위 test(mock)에서 "참고 자료 블록만 차이" byte-identical 입증(S1 commit f22a53d).

## 3. ★ 핵심 발견 (측정 도구의 한계 — 실험의 진짜 수확)

```
generic critic 차원(intent_fit/hook_strength/structure/feasibility/...)에서는
PKM 주입의 효과가 검출되지 않는다 (B−A ≈ +0.013, 노이즈 내).
```

해석 — 이건 "PKM 무용" 결론이 **아니다**. critic 은 **일반 품질**을 재는데, 좋은 generic plan 과
개인화된 plan 둘 다 일반 품질은 높게 받는다. PKM 의 가치는 **"이 브랜드/사용자에 맞는가(fit)"**
+ 일관성 + (누적 시) compounding 이며, **generic critic 은 이 fit 을 분리해서 못 본다.**

→ 직전 moat 리서치와 정합: moat 는 "더 높은 generic 품질"(=commodity)이 아니라 **fit·일관성·누적**.
  따라서 generic 품질만 재면 항상 flat 하게 나오는 게 당연하다.

## 4. 함의 — S2 측정 설계 보강 (★ 결과가 다음 단계를 바꾼다)

S1 이 게이트 역할을 했다: generic critic 하나로 H1 을 재면 안 된다. S2 진입 전 측정에 추가:

```
(a) 개인화 적합도(fit/adherence) 측정 — 객관 규칙 + LLM judge:
    - Arm B 출력이 brand_guide 를 지키는가? (예: '최저가' 회피, '손글씨/담백' 톤)
    - locked_preferences 준수? (예: '과한 자막 지양')
    - series_format 반영? (예: '오프닝 5초 로스팅 b-roll')
    → A 는 이 정보를 받지 못했으므로 구조적으로 fit 이 낮아야 정상. 이게 진짜 B−A 신호.
(b) 사람 blind 선호(S3) — generic 품질 동률일 때 "어느 게 이 브랜드에 더 맞나" 선택.
```

★ S1 미측정: 주입(8 entries)은 확인했으나 **Arm B 출력이 실제로 PKM 을 따랐는지(adherence)** 는
  아직 안 쟀다 — 그게 (a)이고 S2 1순위.

## 5. 체크포인트 (나→가→다 직전 판단)

- generic 품질 lift = flat. **그러나 이는 측정 도구 문제**이지 PKM 기각 근거가 아니다.
- 권고: **가/다 투자 전, (a) fit/adherence 측정을 S2 로 먼저** 넣어 "B 가 PKM 을 실제로 반영하고 그게
  fit 을 올리는가"를 확인. fit 신호가 잡히면 → 가/다 진행. fit 도 flat 이면 → 주입 방식/프롬프트 재설계.
- 즉 "더 깊게 측정한 뒤" 빌드 — 1차 flat 은 멈춤이 아니라 **측정 보강 신호**.
