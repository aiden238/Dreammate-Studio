# docs/contract_changes

## 목적

`docs/contracts/` 변경 제안서. contract 본문 직접 수정 금지 → 항상 이 폴더에 제안서 생성.

## 생성 주체

이 폴더의 파일은 `contract-change` Skill에 의해 생성된다.

## 파일 명명 규칙

`{YYYY-MM-DD}-{contract-name}-{change-summary}.md`
예: `2026-05-24-db_schema-add-choice-logs-table.md`

## 보존 정책

- 즉시 보존
- 승인 후에도 보관 (변경 이력 추적)

## 인덱스

(자동 갱신은 phase-complete Skill에 의해)
