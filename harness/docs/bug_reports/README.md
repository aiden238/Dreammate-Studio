# docs/bug_reports

## 목적

bug-triage Skill로 분류된 버그 리포트를 보관한다.

## 생성 주체

이 폴더의 파일은 `bug-triage` Skill에 의해 생성된다.

## 파일 명명 규칙

`{YYYY-MM-DD}-{severity}-{slug}.md`
예: `2026-05-24-high-output-schema-validation-fail.md`

심각도: `critical`, `high`, `medium`, `low`

## 보존 정책

- 즉시 보존
- 해결 후에도 보관 (재발 추적용)

## 인덱스

(자동 갱신은 phase-complete Skill에 의해)
