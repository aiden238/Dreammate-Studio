# Skill: docs-design

## Purpose

Claude 또는 다른 기획형 모델이 `docs-design` 작업을 수행할 때 사용하는 검토 절차다.

## Procedure

1. PROJECT_STATE.md 확인
2. PHASE_REGISTRY.md 확인
3. 현재 Phase 확인
4. 관련 contracts 확인
5. 장점, 단점, 리스크, 누락 요소 분리
6. contracts 변경은 직접 적용하지 않고 제안
7. 결과를 교차검증 가능한 형식으로 정리

## Output Format

```md
# Review Result

## 1. Summary
## 2. Strengths
## 3. Weaknesses
## 4. Risks
## 5. Missing Elements
## 6. Recommendations
## 7. Next Actions
```
