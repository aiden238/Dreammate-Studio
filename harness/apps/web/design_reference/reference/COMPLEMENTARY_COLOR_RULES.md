# Flame × Cyan Complementary Color Rules

## 권장 비율

- 차가운 작업 UI: 70%
- 아이보리 서적 카드: 20%
- 따뜻한 불꽃 포인트: 10%

## 역할별 색상

| 역할 | 색상 |
|---|---|
| 앱 배경 | `#07131D`, `#0B2232`, `#123545` |
| 패널 | `#102B3A`, `#173E50` |
| 주요 CTA | `#43E7F2 → #2F8CFF → #6B6CFF` |
| 선택·포커스 | `#43E7F2` |
| 정보·진행 | `#2F8CFF` |
| 성공 | `#63D9B2` |
| 브랜드 로고 | `#FED825 → #FE7E01 → #FD5A00 → #C32301` |
| 서적 카드 | `#F7EFE0`, `#E7DCCB` |

## 금지

- 주황 CTA와 파란 CTA를 같은 우선순위로 혼용
- 모든 카드에 불꽃 그라데이션 사용
- 시안색을 긴 본문 텍스트로 사용
- 파랑과 주황을 50:50으로 사용해 화면을 산만하게 구성
