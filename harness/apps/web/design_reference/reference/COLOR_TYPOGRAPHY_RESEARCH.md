## 2. 폰트 선정 기준

직접적인 학생·기획자 전체 선호도 조사가 아니라, 실제 사용 맥락을 기준으로 선정했다.

### Paperlogy

- 프레젠테이션을 목적으로 제작
- 기본 자간과 도형·글자 중심을 발표 자료에 맞게 조정
- 고정폭 숫자를 지원
- 9개 굵기 제공
- Hero, 페이지 제목, 기획 카드 제목에 적용

### SUIT Variable

- UI 본문용으로 설계
- 한글과 영문·숫자 간 조화
- 버튼과 아이콘의 중앙 정렬을 고려한 vertical metrics
- 9개 굵기와 variable format 지원
- 본문, 버튼, 사이드바, 입력창에 적용

### Noto Serif KR

- 기존 Claude풍 서적 카드의 에디토리얼 분위기를 유지
- 전체 UI가 아니라 대본, 인용문, 책 페이지의 긴 문장에만 제한 적용

## 3. 디자인 원칙

1. 전체 화면을 노랑·주황으로 채우지 않는다.
2. 배경은 깊은 불씨색을 사용하고, 황금색은 CTA와 선택 상태에 집중한다.
3. 진홍색은 깊이감과 경계에 사용하고 오류색과 혼동되지 않게 한다.
4. 기획 제목은 Paperlogy로 강하고 빠르게 읽히게 한다.
5. UI 본문은 SUIT로 정돈한다.
6. 서적 카드는 아이보리 질감과 세리프 본문을 유지한다.
