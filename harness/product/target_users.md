## 0. 타겟 사용자 정의

```
MVP 핵심 타겟 (Primary):  1인 마케터
MVP 부 타겟 (Secondary): 소규모 브랜드 매니저
MVP 후 타겟 (Tertiary):  콘텐츠 크리에이터
비-타겟:                 영상 편집 전문가 / 대기업 콘텐츠팀
```

각 타겟별 페르소나는 §1~3에 상세. §6 사용 시나리오에서 행동 패턴 매핑.

## 1. 페르소나 1 — 1인 마케터 (Primary)

### 인구통계

```
이름:       김지영 (가명)
나이:       30대 초반
직업:       1인 운영 브랜드 / 소상공인 마케팅 담당
거주:       서울 / 수도권 중심
교육:       대학 졸업 (마케팅 비전공 다수)
연 수입:    3000만~5000만 원 (1인 운영 매출 의존)
```

### 직무 / 일과

```
- 브랜드 운영 (인스타 / 유튜브 / 틱톡 / 블로그)
- 영상 1주 평균 2~5편 기획 + 제작 + 운영
- 마케팅 + 콘텐츠 + CS + 배송까지 1인 담당
- 영상 외주는 부담 (편당 30만~50만원)
- 자체 편집은 CapCut / Canva 사용
```

### 페인 포인트 (시급도 높은 순)

```
1. 영상 1편 기획에 2~4시간 소요 (전체 작업의 가장 느린 단계).
2. "무엇을, 누구한테, 어떻게 말할지" 매번 처음부터 고민.
3. 잘 만들면 잘 만든 거 같은데, 객관 평가 방법 없음.
4. Brand 일관성 (지난 영상 톤과 같은지) 신경 쓸 여유 없음.
5. ChatGPT 사용해봤지만 광고 표현 자주 나오고 영상기획 specific 부족.
```

### 기대 가치 (왜 우리를 쓰는가)

```
- 영상기획 시간을 90% 줄이고 싶다 (시간 = 매출).
- 영상마다 톤이 들쭉날쭉하지 않게 일관성 원함.
- 객관적 품질 점수 (사람한테 평가 받지 않아도 되니까).
- 한국어 친근체 (영어 기술 용어 싫음).
- 광고 표현 안 들어가는 거 (자기 브랜드 톤이 부드러움).
```

### 사용 빈도 / 패턴

```
사용 빈도: 주 3~5회 (영상 제작 빈도와 동일).
사용 시간대: 평일 저녁 (20~22시) 또는 주말 오전.
디바이스:  데스크탑 50% / 모바일 50%.
세션 길이: Discovery는 첫 사용 시 15분, 이후 Quick은 3~5분.
```

## 2. 페르소나 2 — 소규모 브랜드 매니저 (Secondary)

### 인구통계

```
이름:       박서연 (가명)
나이:       30대 중반
직업:       직원 5~30명 회사의 마케팅 / 콘텐츠 담당자
거주:       수도권
교육:       대학 졸업, 마케팅 전공 또는 부전공
연 수입:    4000만~7000만 원
```

### 직무 / 일과

```
- 회사 브랜드의 SNS 채널 1~3개 운영
- 영상 1주 평균 3~7편 (영상 외주 또는 인하우스 제작)
- 기획서 작성 → 디자이너/영상 제작자에게 전달 → QA
- 여러 Series 동시 운영 (예: 신상품 소개 / 고객 후기 / 일상)
```

### 페인 포인트

```
1. 기획서 작성에 시간 많이 소요 (양식 통일, 톤 통일).
2. 외주 제작자에게 기획 의도가 잘 전달 안 됨.
3. Brand 가이드라인 매번 다시 설명해야 함.
4. 여러 Series 동시 운영 시 톤 혼선.
5. 상사·동료에게 기획안 보여줄 때 객관 근거 부족.
```

### 기대 가치

```
- 표준 기획서 양식 자동 생성.
- Brand Memory로 매번 같은 톤 유지.
- Series별 컨텍스트 분리 (Quick Mode).
- Critic 점수로 내부 설득 자료 확보.
- 4계층 데이터 모델로 정리.
```

### 사용 빈도 / 패턴

```
사용 빈도: 주 5~10회 (업무 시간 중).
사용 시간대: 평일 10~17시.
디바이스:  데스크탑 80% / 모바일 20%.
세션 길이: 평균 8~15분 (외주 발주 전 정리에 사용).
```

## 3. 페르소나 3 — 콘텐츠 크리에이터 (Tertiary)

### 인구통계

```
이름:       이민준 (가명)
나이:       20대 후반
직업:       유튜버 / 인스타 크리에이터 / 틱톡커 (수익화 진행 중)
거주:       전국 분산
교육:       대학 재학 또는 졸업, 비전공 다수
연 수입:    1000만~3000만 원 (콘텐츠 + 부업)
```

### 직무 / 일과

```
- 본인 채널 1~3개 운영 (구독자 1만~10만 규모)
- 영상 1주 평균 3~10편 (쇼츠 위주)
- 본인이 모든 단계 담당 (기획·촬영·편집·운영)
- 다음 영상 아이디어 부족이 가장 큰 스트레스
```

### 페인 포인트

```
1. "다음 영상 뭐 만들지" 결정에 가장 많은 시간 소비.
2. 자기 채널 콘셉트와 톤 일관성 유지 어려움 (특히 쇼츠 양산 압박).
3. 트렌드 따라가야 한다는 압박 vs 본인 정체성 유지의 갈등.
4. 광고적 표현 (협찬 받았을 때) vs 본인 톤의 부조화.
5. 데이터 기반 의사결정 익숙하지 않음.
```

### 기대 가치

```
- 영상 아이디어 자동 생성 (3개 후보 비교).
- Brand Memory로 채널 정체성 유지.
- 한국어 친근체 + 광고 표현 차단.
- Quick Mode로 빠른 결과 (5분 이내).
- 모바일 친화 (PWA).
```

### 사용 빈도 / 패턴

```
사용 빈도: 주 5~15회 (콘텐츠 양산 시).
사용 시간대: 불규칙 (밤 22시~새벽 02시 다수).
디바이스:  모바일 70% / 데스크탑 30%.
세션 길이: Quick Mode 평균 2~5분.
```

## 5. 학습형 진입 시나리오 (Discovery 흐름)

신규 사용자가 처음 들어왔을 때 Discovery Wizard 5단계로 학습.

```
1단계: Brand 등록 (이름, 한 줄 설명, 톤)
2단계: Domain 선택 (뷰티 / 푸드 / 교육 등 카드 5장 = 4추천 + 1직접입력)
3단계: Series 등록 (콘텐츠 묶음 이름, 주기)
4단계: 이번 영상 타겟 선택 (페르소나 카드 5장)
5단계: 톤·메시지 방향 선택 (카드 5장)
       → 한 줄 기획 방향 승인 카드 → AI 생성 시작
```

각 단계에서 사용자 선택은 모두 4계층 데이터 모델에 저장. 다음 영상은 Quick Mode로 자동 진입.

→ `apps/web/design.md` §Discovery, `product/user_scenarios.md` 시나리오 1

## 6. 반복 사용 시나리오 (Quick Mode)

같은 Brand / Series에서 영상 추가 시.

```
1. 사용자 입력: "이번 주 신상품 소개 영상" (한 줄)
2. 시스템 자동 분기: 기존 Series 컨텍스트 발견 → Quick Mode
3. 부족 정보 1~2개 질문 (예: "주력 셀링 포인트는?")
4. 한 줄 방향 승인 카드 (Brand 톤 자동 상속)
5. AI 생성 → 결과 (90초 이내)
```

→ `apps/web/design.md` §Quick Mode, `product/user_scenarios.md` 시나리오 2

## 7. 비-타겟 사용자 (MVP에서 다루지 않음)

```
✗ 영상 편집 전문가
  - 영상 편집·후반 작업이 본업.
  - 기획은 외부에서 옴 (감독, PD).
  - 본 서비스의 가치 (기획 도움)와 핵심 요구 불일치.

✗ 대기업 콘텐츠팀
  - 사내 기획 인력이 충분 (3~10명).
  - 외부 컨설팅도 사용.
  - 4계층 데이터 모델보다 자체 시스템 우선.
  - Phase 21+에서 enterprise tier 검토 가능.

✗ 영화 / 방송 전문 PD
  - 영상 매체 문법이 본 서비스 도메인 (SNS 숏폼 / 유튜브)과 다름.
  - 본 서비스의 hook 패턴이 적용 어려움.

✗ 영상 제작 자동화를 원하는 사용자
  - 본 서비스는 영상기획 AI지 영상 제작 AI가 아님.
  - 영구 제외 (mvp_non_goals.md §1).
  - 사용자가 본 서비스의 기획안으로 다른 도구를 사용하는 협업은 가능.
```

비-타겟에게 명확히 거절 (혼동 방지):

```
- 영상 자동 편집 요청 → "본 서비스는 영상기획만 도와드려요. 편집은 다른 도구를 추천드릴게요."
- 대기업 enterprise 요청 → "Phase 21+에서 검토 예정이에요."
```

## 8. 페르소나별 핵심 측정 지표

각 페르소나별로 추적해야 할 지표.

```
1인 마케터:
  - 영상 1편당 평균 기획 시간 (시각: 60분 → AI 사용 시 6분)
  - 주간 영상 수 증가율
  - Brand Memory 활용 빈도

브랜드 매니저:
  - 표준 기획서 사용 횟수
  - 외주 발주 전 사용 비율
  - 회사 내부 공유 횟수

크리에이터:
  - 아이디어 후보 채택률 (3개 중 1개 선택)
  - 모바일 사용 비율
  - 평균 세션 길이
```

→ `eval/regression_eval.md` 측정 지표와 정합

## 10. Open Questions

1. 페르소나 1 (1인 마케터)와 페르소나 3 (크리에이터)의 경계가 모호 — 분리 vs 통합 검토 필요.
