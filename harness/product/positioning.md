## 0. 한 줄 포지셔닝

> **영상 제작 도구가 아니라, 영상기획 전용 AI 에이전트.**

영상을 "만들기 전"에 필요한 모든 기획 판단을 도와주는 한국어 특화 AI 파트너.

---

## 1. 시장 정의

```
1차 시장 (직접 경쟁): 영상기획 SaaS
- 거의 비어 있다 (전통 컨설팅 또는 frelance 기획자가 주류).

2차 시장 (인접 경쟁): AI 도구 (콘텐츠 생성)
- ChatGPT, Claude, Gemini, Jasper, Copy.ai 등.
- 우리는 "영상기획" 도메인 특화로 차별.

3차 시장 (대체재): 콘텐츠 마케팅 컨설팅
- 편당 50만~200만원, 1~2주 소요.
- 우리는 "AI 자동화 + 즉시 결과 + 저비용"으로 대체.
```

시장 규모 추정 (한국 기준, 2026):

```
- 1인 마케터 / 소규모 브랜드 운영자: ~30만 명
- 콘텐츠 크리에이터 (유튜브/인스타 활성): ~10만 명
- 합계 TAM (영상기획 AI 도구 시장): ~40만 명
- SAM (한국어 친화 + 영상 도메인 특화): ~25만 명
- SOM (3년 이내 도달 가능): ~5만 명
```

→ Phase 21+에서 글로벌(영어/일본어) 확장 시 시장 10배 이상

## 2. 타겟 세그먼트

상세 페르소나는 `product/target_users.md` 참조. 여기서는 포지셔닝 관점 요약.

```
세그먼트 1: 1인 마케터 (Primary, MVP 핵심 타겟)
- 1인 운영 브랜드 / 소상공인 / 작은 회사의 마케팅 담당.
- 영상 기획·제작·운영을 혼자 또는 적은 인력으로.
- 시간 압박. 외주는 부담. 자체 기획 품질에 자신 없음.

세그먼트 2: 소규모 브랜드 매니저 (Secondary, MVP)
- 직원 5~30명 회사의 마케팅/콘텐츠 담당자 1~3명.
- 외주 영상 제작은 가능하지만 기획은 사내에서.
- Brand 일관성이 중요. 여러 Series 동시 운영.

세그먼트 3: 콘텐츠 크리에이터 (Tertiary, MVP 후반)
- 개인 유튜버 / 인스타 크리에이터 / 틱톡커.
- 콘텐츠 양산 압박. 기획 단계가 가장 느림.
- "다음 영상 뭐 만들지" 결정에 시간 소비.
```

비-타겟 (MVP에서 다루지 않음, `product/target_users.md` §비-타겟 상세).

```
- 영상 편집 전문가 (편집 결과물이 목적, 기획은 외부에서 옴)
- 대기업 콘텐츠팀 (자체 기획자 + 외부 컨설팅 사용)
- 영화/방송 전문 PD (영상 매체 문법이 본 서비스 도메인과 다름)
```

## 3. 경쟁 분석

### 3.1 ChatGPT / Claude / Gemini (범용 LLM)

```
강점:
- 사용자 친숙 (이미 사용 중).
- 자유도 높음 (어떤 요청이든 가능).
- 무료 또는 저렴.

약점:
- 영상 도메인 지식 얕음 (광고적 표현 자주 생성, hook 패턴 부족).
- Brand 일관성 유지 불가능 (대화 종료 시 컨텍스트 손실).
- 한국어 친근체 + 광고 차단 필터 부재.
- 4계층 데이터 모델 없음 (User/Brand/Domain/Series/Video 구조 부재).

우리의 차별:
- 영상기획 전용 LLM Wiki + RAG (도메인 지식 축적).
- Brand Memory 자동 추출 + 영구 저장.
- Intent Filter로 영상기획 외 입력 차단 (혼동 방지).
- Critic Agent로 객관 평가 점수 제공.
```

### 3.2 영상 편집 AI (CapCut, Runway, Pictory 등)

```
강점:
- 영상 자동 생성 가능 (텍스트 → 영상).
- TTS / BGM / 자막 자동.

약점:
- 기획 단계 없음 (사용자가 직접 prompt 작성).
- 결과물이 평준화 (다른 사용자와 차별 어려움).
- 기획 품질이 떨어지면 영상 품질도 떨어짐.

우리의 차별 / 보완 관계:
- 우리 = 기획 단계 전담 → 사용자가 본 서비스의 기획안을 가지고 영상 편집 AI 사용 가능.
- 협업 가능성 (Phase 11+ 외부 도구 연동 검토).
- 우리는 영상을 만들지 않는다 (`docs/contracts/mvp_non_goals.md`).
```

### 3.3 전통 기획 컨설팅 / 외주 기획자

```
강점:
- 깊이 있는 맞춤 기획.
- 브랜드 전략 통합.

약점:
- 비용 (편당 50만~200만원).
- 시간 (1~2주 이상).
- 일관성 (담당 컨설턴트 교체 시 톤 변화).

우리의 차별:
- 즉시 결과 (Discovery 5분 / Quick 90초).
- 저비용 (MVP는 무료, Phase 11+ 유료 도입 시 $9.99/월).
- Brand Memory로 사용자 본인의 톤 일관 유지.
```

| 항목 | 우리 | ChatGPT | 영상 편집 AI | 전통 컨설팅 |
|---|---|---|---|---|
| 영상기획 도메인 특화 | ✓ | ✗ | ✗ | ✓ |
| 영상 제작 자동화 | ✗ | ✗ | ✓ | ✗ |
| Brand 일관성 | ✓ | ✗ | ✗ | △ |

| 즉시 결과 (1분 이내) | ✓ | ✓ | △ | ✗ |

| 비용 | 무료~저가 | 무료~저가 | 중간 | 고가 |

## 4. 우리의 차별 가치 (3개)

### 4.1 4계층 데이터 모델 (Brand 일관성)

```
User → Brand → Domain → Series → Video Project

- 한 사용자가 여러 Brand 운영 가능.
- Brand별 Domain (산업/카테고리)과 Series (콘텐츠 묶음) 관리.
- 모든 Video Project가 상위 Brand의 톤·정체성 자동 상속.
- Brand Memory 자동 추출로 사용할수록 일관성 강화.
```

### 4.2 학습형 RAG (5단계 승격)

```
사용자 피드백 / 외부 시드 / LLM Wiki 항목
  → candidate_knowledge (pending)
  → quality_filter (filtered)
  → evaluation (evaluated)
  → human_review (approved)
  → promotion (promoted) → 실 RAG 사용

품질 보장: 광고 표현 / PII / 중복 자동 차단.
시간이 갈수록 시스템이 똑똑해진다.
```

→ `knowledge/rag/promotion_rule.md`, `docs/contracts/rag_data_contract.md`

### 4.3 한국어 특화 (광고 차단 + 친근체)

```
- 광고적 과장 표현 차단 ("최고의", "혁신적인" 등 사전).
- 친근체 응답 (~예요, ~해주세요).
- 영어 기술 용어 번역 (timeout → "응답이 늦어졌어요").
- 한국 콘텐츠 시장 친화 (브랜드 톤·소비자 정서).
```

→ `docs/contracts/output_schema.md`, `eval/brand_consistency_eval.md`

## 5. 메시지 톤 (커뮤니케이션 가이드)

대내·대외 메시지 작성 시 모두 준수.

```
1. 정중하고 친근한 (~예요, ~해드릴게요).
2. 광고적 과장 표현 일절 금지:
   - 금지: "최고의", "혁신적인", "획기적인", "유일한", "압도적인", "완벽한"
   - 대안: "꼼꼼히 정리해드려요", "단단한 기반을 만들어요"
3. 영어 기술 용어 사용 시 한국어 병기 또는 풀어 쓰기.
4. 사용자의 멈춤을 인정 ("막막하시죠?", "고민되시는 부분이 있다면").
5. AI를 "AI"로 칭하지 않고 "도우미", "파트너"로 칭한다 (영업 상황 제외).
6. 비교 광고 (경쟁사 직접 비교) 금지.
```

위반 시: 사전 검증(LLM 응답 광고 단어 필터) + 사후 검토(인간 리뷰).
→ `docs/contracts/output_schema.md` §광고 단어 차단

## 6. 포지셔닝 명제 (Positioning Statement)

내부 의사결정 기준으로 사용.

```
"For" 1인 마케터·소규모 브랜드·콘텐츠 크리에이터
"Who" 영상기획에 시간·비용 부담을 느끼는
"Our product" 영상기획 AI 에이전트는
"That" 한국어 특화 + Brand 일관성 + 객관 품질 평가를 제공한다
"Unlike" ChatGPT (범용 LLM) / 영상 편집 AI / 전통 컨설팅
"Our product" Discovery+Quick Hybrid UX + 4계층 데이터 + 학습형 RAG로 차별화한다
```

## 7. 메시지 우선순위 (광고/마케팅 시)

```
1순위 (모든 외부 노출에 사용):
  "영상기획에 들이는 시간을 90% 줄여드려요."

2순위 (Brand 강조 시):
  "사용할수록 우리 브랜드 톤을 기억해요."

3순위 (품질 강조 시):
  "AI가 만든 후 AI가 다시 평가해드려요. (Critic Agent)"

4순위 (한국어 강조 시):
  "한국어 + 광고 표현 자동 차단."
```

위 메시지는 모두 §5 톤 가이드 준수 (광고 단어 없음).

## 9. Open Questions

1. "1위" 포지셔닝 (영상기획 한국어 1위) 도달 시점 — 사용자 수 / 매출 / 인지도 중 기준 확정 필요.
2. ChatGPT가 영상기획 도메인을 강화하면 차별 약화 가능성 — 학습형 RAG의 누적 효과로 대응 가능한지.
3. 비교 광고 금지 원칙이 마케팅 효과를 약화시키는지 — 측정 방법 필요.
4. 메시지 톤 "정중하고 친근"이 1인 크리에이터 타겟에는 무겁게 느껴질 수 있음 — A/B 검증.
5. 광고 표현 차단이 너무 엄격해서 사용자가 답답해 하는 사례 — sensitivity 조정 기준.
