# Dreammate Studio 2분 발표 대본

## 발표 제목

Dreammate Studio — 영상기획을 실행 가능한 계획으로 바꾸는 AI 에이전트

## 2분 발표 대본

### 0:00 ~ 0:25 / 문제 정의

제가 진행 중인 프로젝트는 Dreammate Studio라는 영상기획 AI 에이전트입니다. 영상 제작을 시작할 때 가장 어려운 부분은 아이디어 자체보다, 그 아이디어를 브랜드 방향, 타깃, 콘텐츠 구조, 실행 계획으로 정리하는 과정입니다.

### 0:25 ~ 0:55 / 비전과 해결 방식

그래서 이 프로젝트는 사용자가 막연한 아이디어를 입력하면, AI가 아키네이터처럼 질문을 던지면서 브랜드 방향을 좁혀갑니다. 이후 타깃과 레퍼런스를 정리하고, 최종적으로 영상 기획안과 실행 WBS까지 연결하는 것을 목표로 합니다.

### 0:55 ~ 1:25 / 아키텍처

구조는 Next.js PWA가 사용자 화면을 담당하고, FastAPI BFF가 인증과 기획 요청을 처리합니다. 내부에서는 MOA Orchestrator가 여러 기획 후보를 만들고, RAG Lite가 근거를 보강하며, Critic Agent가 품질을 검증합니다. 선택 결과와 피드백은 Supabase에 저장됩니다.

### 1:25 ~ 1:55 / WBS

현재 WBS 기준으로 문제 정의, UX 설계, RAG Lite, MOA Lite, 결과 저장, MVP 통합 테스트까지 완료했습니다. 지금은 발표 요구사항에 맞춰 GitHub Pages에서 WBS와 아키텍처를 한 번에 확인할 수 있는 페이지를 구성했습니다.

### 1:55 ~ 2:00 / 마무리

이 프로젝트의 핵심은 AI가 단순히 답변하는 것을 넘어, 영상기획 과정을 구조화하고 실행 관리까지 연결하는 것입니다.

## 발표 운영 순서

1. PC에서 GitHub Pages URL을 먼저 엽니다.
2. 스마트폰 타이머를 2분으로 맞춥니다.
3. URL 화면이 정상 표시되면 타이머를 시작합니다.
4. 문제 정의 → 해결 방식 → 아키텍처 → WBS 순서로 발표합니다.
5. 타이머가 끝나면 마무리 문장으로 종료합니다.

## 한 문장 요약

Dreammate Studio는 영상 아이디어를 브랜드 방향, 타깃, 기획안, WBS까지 연결하는 영상기획 AI 에이전트입니다.
