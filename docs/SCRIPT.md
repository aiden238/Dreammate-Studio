# Dreammate Studio 2분 발표 대본

> 그대로 읽어 내려가는 **2분 완성 대본**(읽기용). 분량 기준 분당 약 375자.
> 7분 버전은 `presentation/script-7min.md`, 슬라이드는 `presentation/interim.md`.

## 발표 제목

Dreammate Studio — 영상 아이디어를, 쓸수록 내 브랜드를 학습하는 영상기획 AI 에이전트

## 2분 발표 대본

### 0:00 ~ 0:20 / 소개

안녕하세요. 저는 영상기획 AI 에이전트, **Dreammate Studio**를 만들고 있습니다. 영상을 대신 만들어주는 도구가 아니라, 만들기 **"전"의 기획**을 도와주는 시스템입니다.

### 0:20 ~ 0:50 / 문제·가치·차별점

영상에서 가장 중요한 건 아이디어 하나보다 **브랜드 방향**입니다. 1인 마케터는 영상 한 편 기획에 두세 시간이 걸리고, 톤을 일관되게 유지하기도 어렵습니다. 그래서 저희는 막연한 아이디어를 **브랜드 방향·타깃·메시지·기획안·실행계획(WBS)**까지 구조화합니다. 핵심 차별점은 "더 잘 만든다"가 아니라, **"쓸수록 내 브랜드에 맞춰진다"**는 개인화입니다.

### 0:50 ~ 1:15 / 해결 방식

방식은 **질문형 AI**입니다. 사용자가 "쇼츠 만들고 싶다"처럼 단순하게 입력하면, AI가 브랜드 정체성과 타깃, 톤을 질문으로 좁혀갑니다. 그다음 **기획안 후보 세 개**를 만들고, **Critic 에이전트가 품질을 평가해 최대 두 번까지** 다시 쓰게 합니다. 사용자의 선택과 피드백은 다음 기획에 반영됩니다.

### 1:15 ~ 1:35 / 아키텍처

구조는 간단합니다. 프론트는 **Next.js PWA**, 백엔드는 **FastAPI**, 데이터는 **Supabase**입니다. 입력이 들어오면 AI 엔진이 기획을 만들고, 근거 검색과 품질 검증을 거쳐 저장됩니다.

### 1:35 ~ 1:55 / 진행 상황 (정직)

현재 핵심 파이프라인은 모두 동작하고 **테스트 814개를 통과**했습니다. 실제 모델로 기획안을 생성해 **데이터베이스에 저장하는 것까지 라이브로 검증**했습니다. 다만 일부 기능은 아직 켜는 단계이고, 화면 완성도와 사람 품질 검증은 다음 작업입니다.

### 1:55 ~ 2:00 / 마무리

정리하면, Dreammate Studio는 영상 아이디어를 **브랜드 전략과 실행 계획**으로 바꾸는 영상기획 AI 에이전트입니다. 감사합니다.

## 발표 운영 순서

1. PC에서 GitHub Pages URL을 먼저 띄워 둔다 (cold start 회피).
2. 스마트폰 타이머를 2분으로 맞춘다.
3. URL 화면이 정상 표시되면 타이머를 시작한다.
4. 소개 → 문제·가치 → 해결 → 아키텍처 → 진행 순서로 발표한다.
5. 타이머가 끝나면 마무리 문장으로 종료한다.

## 한 문장 요약

Dreammate Studio는 영상 아이디어를 브랜드 방향·타깃·메시지·기획안·WBS까지 연결하는, 쓸수록 내 브랜드를 학습하는 영상기획 AI 에이전트입니다.
