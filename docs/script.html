2분 발표 대본

브랜드 설명을 강화한 2분 발표용 대본입니다.

0:00 ~ 0:20

프로젝트 소개

제가 진행 중인 프로젝트는 Dreammate Studio라는 영상기획 AI 에이전트입니다. 단순히 영상을 만들어주는 도구가 아니라, 영상 브랜딩과 브랜드 마케팅을 위한 기획 과정을 정리해주는 시스템입니다.

0:20 ~ 0:50

문제·비전과 브랜드 강조

영상에서 가장 중요한 것은 아이디어 하나보다 브랜드 방향입니다. 어떤 브랜드로 보일지, 누구에게 각인될지, 어떤 메시지를 반복해서 전달할지가 정리되지 않으면 영상은 많이 만들어도 흩어집니다. 그래서 Dreammate Studio는 사용자의 막연한 아이디어를 브랜드 방향, 타깃, 메시지, 레퍼런스, 영상 기획안, WBS 순서로 구조화하는 것을 목표로 합니다.

0:50 ~ 1:15

해결 방식

해결 방식은 질문형 AI입니다. 사용자가 “쇼츠를 만들고 싶다”처럼 단순하게 입력하면, AI가 브랜드 정체성, 타깃, 콘텐츠 톤을 질문으로 좁혀갑니다. 이후 브랜드 마케팅에 맞는 영상 기획 후보를 만들고, 사용자의 선택과 피드백을 다음 기획에 반영합니다.

1:15 ~ 1:35

아키텍처 설명

구조는 간단합니다. 사용자가 입력하면 기획 AI 엔진이 브랜드 방향과 영상 기획을 만들고, 근거 검색과 품질 검증을 거칩니다. 그 결과는 저장되고, 최종적으로 GitHub Pages의 WBS 대시보드에서 진행 상황을 확인할 수 있습니다.

1:35 ~ 1:55

WBS 진행 상황

현재 WBS 기준으로 문제 정의, 브랜드 중심 UX 설계, RAG Lite, MOA Lite, 결과 저장, MVP 통합 테스트까지 완료했습니다. 지금은 발표 요구사항에 맞춰 WBS를 카드형 대시보드와 막대그래프로 재구성했습니다.

1:55 ~ 2:00

마무리

정리하면, Dreammate Studio는 영상 아이디어를 브랜드 전략과 실행 계획으로 바꾸는 영상기획 AI 에이전트입니다.

예상 질문 대비

짧은 답변 준비

Q. 일반 챗봇과 차이가 뭔가요?
일반 챗봇은 답변 생성이 중심이고, 이 프로젝트는 브랜드 방향 설정, 타깃 정리, 영상 기획, 품질 검증, WBS 관리까지 하나의 흐름으로 연결하는 점이 다릅니다.

Q. 왜 브랜드가 중요한가요?
영상은 한 편만 잘 만드는 것이 아니라 반복해서 같은 인상을 남겨야 합니다. 그래서 브랜드 방향과 메시지를 먼저 정리해야 영상 마케팅 효과가 커집니다.

Q. 왜 GitHub Pages를 사용했나요?
PC에서 URL만 열면 바로 발표할 수 있고, WBS와 아키텍처를 정적 웹페이지로 안정적으로 보여줄 수 있기 때문입니다.
