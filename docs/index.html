02. Solution Flow

질문형 AI로 브랜드 방향을 좁혀갑니다

1

Brand

브랜드 정체성과 콘텐츠 방향을 질문으로 정리합니다.

2

Target

시청자와 구매·참여 동기를 구체화합니다.

3

Reference

LLM Wiki와 RAG Lite로 기획 근거를 보강합니다.

4

Plan

브랜드 마케팅에 맞는 영상 기획 후보를 생성합니다.

5

WBS

선택된 기획을 실행 가능한 작업 단위로 전환합니다.

사용자 선택 피드백 저장 Brand Memory 준비 다음 기획에 반영
