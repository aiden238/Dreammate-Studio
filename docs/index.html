01 · Vision · 비전

한두 편 잘 돼도, ‘개인 브랜드’로 쌓이진 않습니다

Dreammate Studio는 막연한 영상 아이디어를 브랜드 방향 · 타깃 · 메시지 · 기획안 · 실행 WBS까지 한 흐름으로 연결하는 영상기획 AI 에이전트입니다.
브랜드로 축적한두 편의 성공이 휘발되지 않고, 반복되는 브랜드 자산으로 쌓이게 합니다.
질문으로 구조화막연한 아이디어를 AI가 질문으로 좁혀 ‘실행 가능한 기획’으로 바꿉니다.
실행까지 연결기획에서 끝나지 않고 촬영·편집·업로드 WBS로 분해합니다.

한 문장 비전 — “AI가 영상 아이디어를 브랜드 전략과 실행 계획으로 바꾼다.”

02 · Problem · 문제정의

혼자 다 하는 1인 창작자 — 잘 만들어도 브랜드로 안 쌓입니다

타깃 모호

누구에게 각인될 영상인지 불명확하면 메시지가 약해집니다.

03

브랜딩 전략이 촬영·편집·업로드 작업으로 분해되지 않으면 실행이 멈춥니다.

06 · Implementation · 어떻게 구현했는가

핵심 구현 — 생성·검증·근거·진행을 한 파이프라인으로

① 3안 병렬 생성하나가 아니라 서로 다른 방향의 기획안 3개를 병렬 생성해 선택지를 줍니다.
② Critic + Revise 루프Critic Agent가 canonical 0~1 점수로 평가하고, 기준 미달 시 Rewriter가 최대 2회 개선합니다.
③ RAG Lite 5단계후보→품질필터→평가→승인→승격. 검증된 지식만 pgvector 검색에 들어갑니다.
④ MOA Orchestrator659줄 god-function을 243줄 오케스트레이터로 분해 — 동작 보존(byte-identical).
⑤ SSE Progress 4단계30~60초 생성 대기를 4단계 진행률 + 부분 결과로 보여줍니다.
⑥ Supabase 영속 · RLSJWT httpOnly 쿠키 + 행 수준 보안(RLS)으로 사용자 데이터 격리.

설계 원칙 — 모든 입출력은 contract(단일 진실 소스) 기준. 구현이 contract를 벗어나면 회귀 테스트가 즉시 잡습니다.
