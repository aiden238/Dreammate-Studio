문제·비전 해결 아키텍처 WBS 대본

GitHub Pages · WBS · Mermaid Architecture

영상기획을
실행 가능한 계획으로 바꾸는 AI 에이전트

Dreammate Studio는 막연한 영상 아이디어를 브랜드 방향, 타깃, 레퍼런스, 기획안, WBS로 단계적으로 구조화하는 영상기획 AI 에이전트 플랫폼입니다.

발표 핵심

Phase 10MVP 통합 완료
381pytest 기준선
11PWA routes
17API endpoints

핵심 문장: AI가 답만 주는 것이 아니라, 기획 과정을 구조화하고 실행 관리까지 연결합니다.

01. Planning · Vision

문제는 아이디어가 아니라 구조화입니다

문제 정의

  • 초보자는 브랜드 방향을 정하기 어렵습니다.
  • 타깃과 콘텐츠 톤이 흐리면 영상이 쉽게 흔들립니다.
  • 기획안이 작업 단위로 나뉘지 않아 실행 관리가 어렵습니다.

비전

아이디어 입력
브랜드 방향 정리
타깃·레퍼런스 구체화
영상기획안 생성
WBS 기반 실행 관리

02. Solution Flow

질문형 AI로 방향을 좁혀갑니다

1

Discovery

5단계 카드 질문으로 브랜드 방향을 찾습니다.

2

Target

누구에게 보여줄 영상인지 구체화합니다.

3

Reference

LLM Wiki와 RAG Lite로 근거를 보강합니다.

4

Plan

3개 후보 기획안을 만들고 품질을 검증합니다.

5

WBS

선택된 기획을 작업 단위로 전환합니다.

03. Design · Mermaid

아키텍처 구성

flowchart LR
  U[사용자] --> FE[Next.js PWA]
  FE --> API[FastAPI BFF]
  API --> ORCH[MOA Orchestrator]
  ORCH --> RAG[LLM Wiki + RAG Lite]
  ORCH --> GEN[Plan Generator]
  GEN --> CRITIC[Critic Agent]
  CRITIC --> DB[Supabase Storage]
  DB --> WBS[GitHub Pages WBS]
  DB -.피드백 반영.-> ORCH

설명 순서: 사용자 입력 → 기획 생성 → 근거 보강 → 검증 → 저장 → WBS 확인

05. 2-Minute Script

발표 대본

0:00~0:25 제가 진행 중인 프로젝트는 Dreammate Studio라는 영상기획 AI 에이전트입니다. 영상 제작에서 어려운 부분은 아이디어 자체보다 그 아이디어를 브랜드 방향, 타깃, 콘텐츠 구조, 실행 계획으로 정리하는 과정입니다.

0:25~0:55 이 프로젝트는 사용자가 막연한 아이디어를 입력하면 AI가 질문을 던지면서 브랜드 방향을 좁혀갑니다. 이후 타깃과 레퍼런스를 정리하고, 최종적으로 영상 기획안과 실행 WBS까지 연결합니다.

0:55~1:25 구조는 Next.js PWA가 사용자 화면을 담당하고, FastAPI BFF가 요청을 처리합니다. 내부에서는 MOA Orchestrator가 여러 기획 후보를 만들고, RAG Lite가 근거를 보강하며, Critic Agent가 품질을 검증합니다.

1:25~1:55 현재 WBS 기준으로 문제 정의, UX 설계, RAG Lite, MOA Lite, 결과 저장, MVP 통합 테스트까지 완료했습니다. 지금은 GitHub Pages에서 WBS와 아키텍처를 한 번에 확인할 수 있게 구성했습니다.

1:55~2:00 핵심은 AI가 단순히 답변하는 것을 넘어 영상기획 과정을 구조화하고 실행 관리까지 연결하는 것입니다.
