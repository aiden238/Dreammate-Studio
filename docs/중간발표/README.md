# 중간발표 자료

이 폴더는 Dreammate Studio 중간발표용 자료를 모아둔 폴더입니다.

## 파일

- `Dreammate_Studio_중간발표.pptx`  
  7분 발표 시간 배분에 맞춘 PPT입니다.

- `중간발표_발표대본.md`  
  발표 시간 배분에 맞춘 7분 발표 대본과 Q&A 대비 답변입니다.
