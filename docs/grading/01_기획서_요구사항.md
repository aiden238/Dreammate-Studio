## 1. 비전 (Vision)

**Dreammate Studio는 영상기획 AI 에이전트다.** 영상을 자동 생성·편집하는 도구가 아니라, **막연한 영상 아이디어를 실행 가능한 영상기획안으로 구조화**하는 에이전트다.

> 사용자의 목적·타깃·브랜드 톤을 정리하고, LLM Wiki와 RAG로 근거를 찾은 뒤, 검증 에이전트(Critic)가 기획 품질을 평가·개선한다.

- **지향점**: "무엇을 찍을지/만들지"가 아니라 **"무엇을, 누구에게, 왜, 어떤 메시지로"** 라는 기획 레이어를 책임진다.
- **차별점**: 단발 프롬프트 응답이 아니라 **브랜드 방향 → 타깃 → 메시지 → 레퍼런스 → 영상기획안 → WBS**까지 구조화하고, 사용자별 지식을 **2nd brain(개인 PKM)** 으로 누적한다.

## 2. 문제 정의 (Problem Statement)

| # | 문제 | 현상 |
|---|---|---|
| P1 | **아이디어와 실행 사이의 간극** | "이런 느낌의 영상을 만들고 싶다"는 막연함을, 타깃·메시지·구성으로 옮기는 과정이 비전문가에게 어렵다. |
| P2 | **일반 LLM의 깊이 부족** | 범용 챗봇은 7필드 수준의 얕은 기획(compact)에 그친다. (Phase 12에서 같은 모델로 compact 0.231 vs rich 1.000 = 4.3배 격차를 실측·확정) |
| P3 | **품질 검증의 부재** | LLM 출력은 "그럴듯하지만" 광고적·근거 없는 표현이 섞인다. 자기 점수(Critic)는 낙관 편향(전수 approve)이 있어 신뢰가 어렵다. |
| P4 | **맥락 단절** | 브랜드/시리즈를 반복 작업할 때 매번 처음부터 설명해야 한다 (브랜드 기억 부재). |
| P5 | **한국어 약점** | 다수 임베딩 모델이 한국어 의미 검색에서 약하다 (text-embedding-3-small 0.7 미달 실측). |

**해결 접근**: ① 하이브리드 의도분석(Discovery/Quick) ② RAG/LLM Wiki 근거 검색(한국어 우위 Gemini 임베딩) ③ Critic 검증 + cross-provider judge(사람정렬 계측기) ④ Brand Memory / 개인 PKM 누적.

## 3. 타깃 페르소나 (Target Persona)

| 페르소나 | 특징 | 핵심 니즈 |
|---|---|---|
| **1인 브랜드/크리에이터** | 영상 전문 기획자 없음, 직접 콘텐츠 운영 | 막연한 아이디어를 빠르게 구조화된 기획안으로 |
| **소규모 마케팅 담당자** | 브랜드 톤·메시지 일관성 필요, 시리즈 반복 제작 | 브랜드 기억 + 반복 작업 시 Quick Mode |
| **에이전시 기획 보조** | 다수 브랜드/도메인 동시 관리 | 4계층(Brand→Domain→Series→Video)으로 자산 분리 관리 |

## 4. 핵심 사용자 흐름 (User Flow)

```text
사용자 입력
→ 의도 분석 (Discovery Wizard 또는 Quick Mode 자동 분기)
→ 부족한 정보 질문 (Discovery: 5 카드 / Quick: 1–2 질문)
→ 한 줄 기획 방향 승인
→ LLM Wiki / RAG Lite 검색
→ 영상기획안 생성 (3개, 병렬)
→ Critic Agent 검증 (revise 최대 2회)
→ 결과 저장
→ 사용자 피드백 저장 (Brand Memory 자동 추출)
```

**UX 분기 조건**
- 신규 / Brand 없음 → **Discovery Wizard** (5단계 카드, AI 제안 4 + 직접입력 1)
- 기존 Series → **Quick Mode** (1–2 질문만, 비용 절감)

## 5. 기능 요구사항 (Functional Requirements, FR)

| ID | 요구사항 | 상태 |
|---|---|---|
| **FR-1** | 사용자 입력의 **의도 분석** 후 Discovery/Quick 모드를 자동 분기한다. | ✅ 구현 |
| **FR-2** | 영상기획 외 입력은 **Intent Filter**로 차단한다. | ✅ 구현 |
| **FR-3** | 부족 정보를 질문하고, **한 줄 기획 방향**을 사용자가 승인하게 한다. | ✅ 구현 |
| **FR-4** | **LLM Wiki + RAG Lite**(pgvector)로 근거를 검색해 생성에 주입한다. | ✅ 구현 (RAG ON 시 리뷰 Δ+0.9 실증) |
| **FR-5** | **영상기획안 3개**를 병렬 생성한다 (다양성 위해 멀티 모델 인터페이스). | ✅ 구현 |
| **FR-6** | **Critic Agent**가 canonical 점수(0~1) + 차원별 점수로 평가하고, `revise` 시 **최대 2회** 자동 개선한다. | ✅ 구현 |
| **FR-7** | **추천안(recommended_plan_index)** 을 산출한다. | ✅ 구현 |
| **FR-8** | 광고적·과장 표현("최고의", "혁신적인" 등)을 검사·차단한다. | ✅ 구현 |
| **FR-9** | 생성 결과를 **저장**하고, 선택/피드백(`selected_plans`, `feedback_events`)을 영속화한다. | ✅ 구현 |
| **FR-10** | 피드백에서 **Brand Memory를 자동 추출**해 후보 지식으로 적재한다 (5단계 승격 대기). | ✅ 준비 (추출 훅 + pending 적재) |
| **FR-11** | **4계층 데이터 모델**(Brand→Domain→Series→Video) + 개인 **PKM(2nd brain)** 으로 자산을 관리한다. | ✅ 구현 (`/brain` 4계층 + video 노드) |
| **FR-12** | 30~60초 생성 대기 동안 **SSE 4단계 progress**와 부분 결과를 노출한다. | ✅ 구현 |
| **FR-13** | 사용자 인증(JWT httpOnly cookie) + **RLS**로 사용자별 데이터를 격리한다. | ✅ 구현 (anon JWT 실격리 검증은 운영 단계) |

## 6. 비기능 요구사항 (Non-Functional Requirements, NFR)

| ID | 분류 | 요구사항 |
|---|---|---|
| **NFR-1** | 성능 | 생성 응답은 30~60초 UX를 가정, p95 1초 초과(정상 응답 기준) 시 캐시/인덱스 재검토 (tech_stack ADR §5). |
| **NFR-2** | 신뢰성 | 외부(LLM/RAG/DB) 실패는 **graceful** — plan 생성 차단 없이 `validation.warnings` 마커로 노출. |
| **NFR-3** | 보안 | JWT httpOnly cookie + RLS, PII 마스킹, 프롬프트 인젝션 차단, RAG 데이터 오염 방지(5단계 승격). |
| **NFR-4** | 비용 | revise 최대 2회 상한으로 LLM 호출 폭주 차단, rate_limit 정책 정의(구현은 배포 단계). |
| **NFR-5** | 품질 | golden_set 회귀 + Critic canonical + cross-provider judge(false-approve 10→0)로 절대 품질 게이트. |
| **NFR-6** | 이식성 | DB는 표준 PostgreSQL 호환 유지(Supabase→self-host 마이그 가능), 임베딩/모델은 env로 교체 가능. |
| **NFR-7** | 모바일 우선 | Next.js PWA(next-pwa), 카드 단위 결과, 한 줄 방향 승인 UX. |
| **NFR-8** | 한국어 품질 | 임베딩=Gemini(한국어 우위) / 생성=GPT 분리. |

## 7. MVP 범위 (In-Scope)

- 하이브리드 의도분석(Discovery 5카드 / Quick 1–2질문) + 한 줄 방향 승인
- 영상기획안 3개 생성 + Critic revise(최대 2회) + Rewriter + 추천안
- RAG Lite(pgvector + candidate_knowledge 5단계 승격) + LLM Wiki 보조
- 4계층 데이터 모델 + 개인 PKM(2nd brain) + 결과 저장 + 피드백 + Brand Memory 자동 추출
- SSE 4단계 progress, JWT 인증 + RLS, PWA

## 8. MVP 비범위 (Non-Goals — 영구 제외)

|---|---|
